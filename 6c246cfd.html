Geometry

自动关联目录：Geometry

几何回答的是"形状如何表示，以及如何处理"。

表示的三大类

类别形式判断内外采样表面典型
隐式f(x,y,z)=0f(x,y,z) = 0f(x,y,z)=0易难SDF、CSG、分形
显式（参数）(u,v)→(x,y,z)(u,v) \to (x,y,z)(u,v)→(x,y,z)难易NURBS、细分曲面
离散点云 / 网格难—扫描数据

核心权衡：隐式几何擅长"查询"（这个点在里面吗？离表面多远？），参数几何擅长"生成"（给我曲面上的点）。

隐式表示

代数曲面

x2+y2+z2−r2=0（球面）x^2 + y^2 + z^2 - r^2 = 0 \quad \text{（球面）}x2+y2+z2−r2=0（球面）

二次曲面（球、柱、锥、双曲面）都可以精确表示。

CSG（Constructive Solid Geometry）

用布尔运算组合基本体：

并: min(f1, f2)      （或 f1 < 0 || f2 < 0）
交: max(f1, f2)
差: max(f1, -f2)

优势：复杂形状只用几个基本体 + 布尔运算，紧凑且精确。CAD 里常用。

SDF（Signed Distance Field）

f(p) = 到表面的最短距离（外部为正，内部为负）
关键性质: |∇f| = 1

这个性质带来高效的渲染方法——sphere tracing（球体步进）：

float t = 0.0;
for (int i = 0; i < MAX_STEPS; i++) {
    float d = sdf(ro + rd * t);      // 到最近表面的距离
    if (d < EPS) return hit;          // 命中
    t += d;                           // 安全前进 d（保证不会穿过任何表面）
    if (t > MAX_DIST) break;
}
return miss;

为什么可以前进ddd：因为半径ddd 的球内保证没有表面，所以安全。

应用：

  • 光线步进（无需 BVH）
  • 软阴影（见实时阴影）
  • 环境遮蔽（AO）
  • 碰撞检测
  • 布尔运算的平滑版本（smooth min）

smooth min（让两个形状平滑融合）：

smin(a,b,k)=−1klog⁡(e−ka+e−kb)\text{smin}(a, b, k) = -\frac{1}{k}\log(e^{-ka} + e^{-kb})smin(a,b,k)=−k1​log(e−ka+e−kb)

（指数版，或更便宜的多项式版）

分形

自相似的隐式形状（Mandelbulb、Julia 集）。用 SDF + sphere tracing 渲染。

显式（参数）表示

点云

最简单的表示：一堆(x,y,z)(x,y,z)(x,y,z)。

问题：没有表面信息（法线、拓扑）。

处理：

  • 法线估计：PCA（取邻域协方差矩阵的最小特征向量）
  • 表面重建：Poisson 重建、Delaunay、移动最小二乘（MLS）

多边形网格

工业标准。

顶点: 位置（+ 法线、UV、颜色）
面:   通常是三角形（或四边形）

数据结构：

结构特点
面列表最简单，但邻接查询慢
邻接表顶点→面、面→面
半边（Half-Edge）查询效率最高，几何处理的标准
翼边（Winged-Edge）类似

半边结构：每条边拆成两个有方向的半边，每个半边记录 next、twin（反向半边）、face、vertex。这样"遍历一个顶点的所有邻域"是O(度)O(\text{度})O(度)。

曲线曲面

见 Games102：Bézier、B 样条、NURBS。

网格处理

三个基本操作

操作目的代表算法
细分增面、光滑Loop（三角）、Catmull-Clark（四边形）
简化减面QEM 边坍缩
重划分改善质量各向同性 remeshing

判断网格质量的指标：

  • 三角形形状（越接近等边越好）
  • 顶点 valence（三角网格理想值 6，四边形 4）
  • 无翻转、无自交、无非流形边

Laplace 算子

余切权重 Laplace-Beltrami（离散微分几何的核心工具）：

Δf(vi)=12Ai∑j∈N(i)(cot⁡αij+cot⁡βij) (f(vj)−f(vi))\Delta f(v_i) = \frac{1}{2A_i} \sum_{j \in \mathcal{N}(i)} (\cot\alpha_{ij} + \cot\beta_{ij})\,(f(v_j) - f(v_i))Δf(vi​)=2Ai​1​j∈N(i)∑​(cotαij​+cotβij​)(f(vj​)−f(vi​))

为什么重要：这个离散化收敛到连续的 Laplace-Beltrami 算子，所以基于它的算法（光顺、参数化、形变）都有理论保证。

应用：

  • 网格光顺（f←f+λΔff \leftarrow f + \lambda \Delta ff←f+λΔf）
  • 参数化（解Δu=0\Delta u = 0Δu=0）
  • 形变（ARAP 的迭代求解）
  • 谱分析（拉普拉斯特征函数，几何处理的"傅里叶变换"）

参数化

把三维网格映射到二维（u,vu,vu,v）。必然有畸变。

能量选择：

能量性质代价
Tutte保证无翻转畸变大
LSCM共形（保角）解线性系统
ARAP尽可能刚体，畸变极小迭代，非线性

割缝（Seam）：复杂拓扑必须切开。接缝的位置直接决定畸变大小和纹理连续性。

现代方向

神经隐式表示（Neural Fields）

用神经网络表示 SDF 或辐射场：

NeRF:      (x, y, z, θ, φ) → (color, density)
SDF 网络:  (x, y, z)       → signed distance

优势：

  • 表示能力强（细节不受分辨率限制）
  • 紧凑（一个网络 = 一个场景）

劣势：

  • 训练慢
  • 渲染慢（每次查询要跑网络）
  • 难以编辑

3D 高斯泼溅（3D Gaussian Splatting）

2023 的重要突破：用一堆 3D 高斯表示场景，用光栅化（而不是 ray marching）渲染。

表示:  N 个 3D 高斯，各有位置、协方差（形状）、颜色、不透明度
渲染:  投影到屏幕，按深度排序，alpha 混合

为什么快：利用 GPU 的光栅化管线（而不是每条光线跑网络）。

质量 vs 速度：接近 NeRF 的质量，实时（100+ FPS）的速度。

Nanite（UE5）

虚拟几何：把网格预处理成 LOD 层级，运行时按像素级误差自动选择适合的三角形密度。

核心: 
  - 预先构建 cluster hierarchy（三角形簇的层次）
  - 运行时按屏幕投影大小选择 cluster
  - GPU driven，几乎无 draw call

意义："不用再手工做 LOD 了"——可以直接导入影视级的高模。

几何 vs 渲染的接口

现代实时渲染越来越依赖几何的预处理：

渲染技术依赖的几何数据
光照贴图UV 参数化
SDF 软阴影/AOSDF 或体素化
VXGI体素化
Nanitecluster hierarchy
3DGS高斯参数
法线贴图高模到低模的烘焙（需要对应）

趋势：渲染和几何的边界越来越模糊，很多"渲染问题"其实是"几何数据的组织问题"。

常见坑

  • 网格不是流形：有多个边共享、面朝向不一致 → 很多算法会崩。处理前先修复
  • 法线朝向不一致：面法线方向混乱 → 光照错误、双面渲染异常
  • 退化三角形：面积为零的三角形 → 除法为零、法线计算失败
  • 细分曲面的奇异点：valence ≠ 4 处连续性下降
  • 参数化的翻转：UV 三角形翻转 → 渲染出错。Tutte 嵌入可保证无翻转
  • SDF 的精度：存成低精度（8 bit）时会有明显台阶，需要足够的分辨率或压缩方案
  • 布尔运算会产生退化几何：需要后处理（去重、修复）
  • 泊松重建需要法线朝向一致：朝向乱了结果全错
  • 3DGS 的排序：alpha 混合需要严格深度排序，排序不准会有伪影
