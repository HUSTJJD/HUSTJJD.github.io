柔体

Base Knowledge, Computer Graphics, Simulation 2025-08-10 2026-10-10 3442 字

柔体 vs 刚体 vs 质点弹簧

模型自由度适用物理正确性
刚体6不变形物体✓
质点-弹簧3n3n3n布料、粗略软体✗
有限元（FEM）3n3n3n真实弹性体✓

柔体的核心：用连续介质力学建模，而不是"一堆弹簧"。

连续介质力学基础

形变梯度

物体从参考构型X\mathbf{X}X 变形到当前构型x\mathbf{x}x：

F=∂x∂X\mathbf{F} = \frac{\partial \mathbf{x}}{\partial \mathbf{X}}F=∂X∂x​

F\mathbf{F}F 是3×33 \times 33×3 矩阵，包含了全部的局部形变信息（拉伸、剪切、旋转）。

F = I        → 无形变
F = R（旋转）→ 刚性旋转，无形变（不该产生内力！）
F 非正交部分 → 真正的形变

det⁡(F)\det(\mathbf{F})det(F) 的物理意义：体积变化率。det⁡(F)=1\det(\mathbf{F}) = 1det(F)=1 表示不可压缩。

应变（Strain）

关键要求：应变必须在刚性旋转下不变。否则"转动物体会产生内力"，物理错误。

常用的应变度量：

度量定义特点
Green 应变E=12(FTF−I)\mathbf{E} = \frac{1}{2}(\mathbf{F}^T\mathbf{F} - \mathbf{I})E=21​(FTF−I)旋转不变，但非线性
Cauchy 应变（小应变）ϵ=12(F+FT)−I\boldsymbol{\epsilon} = \frac{1}{2}(\mathbf{F} + \mathbf{F}^T) - \mathbf{I}ϵ=21​(F+FT)−I线性，但大旋转下失效

Green 应变用FTF\mathbf{F}^T\mathbf{F}FTF 而不是F\mathbf{F}F，正是为了消掉旋转（RTR=I\mathbf{R}^T\mathbf{R} = \mathbf{I}RTR=I）。

应力（Stress）

应力是应变的函数（本构关系）：

P=∂W∂F\mathbf{P} = \frac{\partial W}{\partial \mathbf{F}}P=∂F∂W​

WWW 是弹性能密度（strain energy density），P\mathbf{P}P 是 Piola-Kirchhoff 应力。

不同的WWW 对应不同的材料模型。

超弹性材料模型

线性弹性（Saint-Venant-Kirchhoff，StVK）

W=μ∥E∥2+λ2tr(E)2W = \mu \|\mathbf{E}\|^2 + \frac{\lambda}{2}\text{tr}(\mathbf{E})^2W=μ∥E∥2+2λ​tr(E)2

参数含义
μ\muμ剪切模量（抗剪切）
λ\lambdaλ拉梅参数（与体积变化相关）

与工程常用的关系：

E=μ(3λ+2μ)λ+μ,ν=λ2(λ+μ)E = \frac{\mu(3\lambda + 2\mu)}{\lambda + \mu}, \quad \nu = \frac{\lambda}{2(\lambda + \mu)}E=λ+μμ(3λ+2μ)​,ν=2(λ+μ)λ​

EEE = 杨氏模量（刚度），ν\nuν = 泊松比（0~0.5，橡胶约 0.49，软木约 0）。

StVK 的问题：大压缩时会翻转（体积压缩到负，材料"翻面"），不鲁棒。

Neo-Hookean（更鲁棒）

W=μ2(∥F∥2−3)−μlog⁡J+λ2(log⁡J)2,J=det⁡(F)W = \frac{\mu}{2}(\|\mathbf{F}\|^2 - 3) - \mu\log J + \frac{\lambda}{2}(\log J)^2, \quad J = \det(\mathbf{F})W=2μ​(∥F∥2−3)−μlogJ+2λ​(logJ)2,J=det(F)

log⁡J\log JlogJ 项：J→0J \to 0J→0 时能量→+∞\to +\infty→+∞ → 自动防止体积塌陷。

这是实时仿真中最常用的模型（鲁棒且够用）。

共旋转线性模型（Corotated Linear）

W=μ∥F−R∥2+λ2tr(RTF−I)2W = \mu \|\mathbf{F} - \mathbf{R}\|^2 + \frac{\lambda}{2}\text{tr}(\mathbf{R}^T\mathbf{F} - \mathbf{I})^2W=μ∥F−R∥2+2λ​tr(RTF−I)2

其中R\mathbf{R}R 是F\mathbf{F}F 的极分解的旋转部分：F=RS\mathbf{F} = \mathbf{R}\mathbf{S}F=RS。

核心思想：先把旋转剥离（R\mathbf{R}R），剩下的S\mathbf{S}S 才是真正的形变。

这是实时仿真的明星模型：

  • 比 StVK 鲁棒（不会翻转）
  • 比 Neo-Hookean 便宜（不需要log⁡\loglog）
  • 大旋转正确（因为显式处理了R\mathbf{R}R）

需要极分解：F=RS\mathbf{F} = \mathbf{R}\mathbf{S}F=RS，每步都要算（SVD 或迭代法）。这是主要开销。

有限元离散化（FEM）

思路

把物体切成四面体（3D）或三角形（2D）单元，每个单元内假设线性变形。

四面体单元:
  4 个顶点 X0, X1, X2, X3（参考构型）
  4 个顶点 x0, x1, x2, x3（当前构型）
  
  单元内的形变梯度 F 是常数（因为线性插值）
  → 每个单元的应力是常数
  → 力作用在 4 个顶点上

计算单元的 F

F=DsDm−1\mathbf{F} = \mathbf{D}_s \mathbf{D}_m^{-1}F=Ds​Dm−1​

其中：

  • Dm=[X1−X0, X2−X0, X3−X0]\mathbf{D}_m = [\mathbf{X}_1-\mathbf{X}_0,\ \mathbf{X}_2-\mathbf{X}_0,\ \mathbf{X}_3-\mathbf{X}_0]Dm​=[X1​−X0​, X2​−X0​, X3​−X0​]（参考构型，预计算）
  • Ds=[x1−x0, x2−x0, x3−x0]\mathbf{D}_s = [\mathbf{x}_1-\mathbf{x}_0,\ \mathbf{x}_2-\mathbf{x}_0,\ \mathbf{x}_3-\mathbf{x}_0]Ds​=[x1​−x0​, x2​−x0​, x3​−x0​]（当前构型）

Dm−1\mathbf{D}_m^{-1}Dm−1​ 可以预计算——这是 FEM 高效的关键。

单元的内力

f=−∂W∂x=−P⋅∂F∂x\mathbf{f} = -\frac{\partial W}{\partial \mathbf{x}} = -\mathbf{P} \cdot \frac{\partial \mathbf{F}}{\partial \mathbf{x}}f=−∂x∂W​=−P⋅∂x∂F​

展开到 4 个顶点：

(f1f2f3)=−vol⋅P(F)⋅Dm−T\begin{pmatrix}\mathbf{f}_1 & \mathbf{f}_2 & \mathbf{f}_3\end{pmatrix} = -\text{vol} \cdot \mathbf{P}(\mathbf{F}) \cdot \mathbf{D}_m^{-T}(f1​​f2​​f3​​)=−vol⋅P(F)⋅Dm−T​

f0=−(f1+f2+f3)\mathbf{f}_0 = -(\mathbf{f}_1 + \mathbf{f}_2 + \mathbf{f}_3)f0​=−(f1​+f2​+f3​)

（最后一个顶点由力的平衡决定）

这就是完整的 FEM 弹性力计算。

时间积分

FEM 的刚度通常很大 → 显式积分会很不稳定。

方法稳定性代价
显式需要极小Δt\Delta tΔt低
隐式（推荐）无条件稳定每步解线性系统
半隐式中等低

隐式积分需要 Jacobian（力对位置的导数）：

H=−∂f∂x\mathbf{H} = -\frac{\partial \mathbf{f}}{\partial \mathbf{x}}H=−∂x∂f​

对 FEM，H\mathbf{H}H 是稀疏对称的（每个单元贡献12×1212 \times 1212×12 的小块）→ 共轭梯度法求解很高效。

实时柔体的实用方案

方案对比

方案物理正确性速度实现难度
质点-弹簧低快低
Position Based Dynamics中快低
Projective Dynamics中高中中
FEM（隐式）高慢高

PBD 做柔体

把 FEM 的应变作为约束：

约束: C(x) = 应变 - 目标应变 = 0
直接投影（不用力）

优点：无条件稳定，快。 缺点：刚度依赖迭代次数（不是真物理）。

XPBD 修正了时间步依赖，是 UE Chaos、NVIDIA Flex 的基础。

Projective Dynamics（2014）

思路：把隐式的能量最小化拆成两步交替：

1. Local step:  每个约束独立地找最近的"投影位置"（可并行）
2. Global step: 解一个线性系统，把投影结果组合起来（矩阵是常数，可预分解！）

关键优化：全局步的矩阵M/Δt2+L\mathbf{M}/\Delta t^2 + \mathbf{L}M/Δt2+L 是常数（Laplacian），可以预计算 Cholesky 分解 → 每帧只做回代，极快。

效果：接近隐式 FEM 的质量，接近显式方法的速度。

这是近年来实时柔体最重要的进展。

特殊：不可压缩性

泊松比ν→0.5\nu \to 0.5ν→0.5 时（橡胶、生物组织）要近似不可压缩。

问题：线性单元的 FEM 会出现体积锁定（volumetric locking）——单元过于僵硬，无法变形。

解法：

方法思路
混合单元压力作为独立变量
减小λ\lambdaλ牺牲一点不可压缩性换稳定（实用做法）
高阶单元二次插值
XPBD 的体积约束直接约束单元体积

断裂与塑性

断裂（Fracture）

1. 计算应力
2. 超过阈值 → 单元分离/顶点分裂
3. 重新网格化（或预切割）

预切割（pre-fracture）：离线把物体切成碎块，运行时按冲击分离。游戏里最常用（快、可控、可美术控制）。

真实断裂需要运行时重网格化，代价高。

塑性（Plasticity）

形变超过阈值后，静止长度永久改变。

Lrest←Lrest+ΔL（当形变超过屈服点）L_{rest} \leftarrow L_{rest} + \Delta L \quad \text{（当形变超过屈服点）}Lrest​←Lrest​+ΔL（当形变超过屈服点）

应用：金属弯曲、黏土、雪。

参数与调参

参数含义典型值
杨氏模量EEE刚度橡胶10610^6106、肌肉10410^4104、钢101110^{11}1011
泊松比ν\nuν不可压缩程度0.3（普通）、0.49（橡胶）
密度ρ\rhoρ质量1000（水）

实时仿真中通常不用真实值（数值范围太大导致不稳定），而是调"看起来对"的相对值。

常见坑

  • 用了 Cauchy（小）应变做大旋转：转动物体会产生虚假内力（物体自己"拧"起来）。用 Green 应变或共旋转模型
  • Dm−1\mathbf{D}_m^{-1}Dm−1​ 退化：初始四面体太扁（体积接近 0）→ 矩阵不可逆 → 数值爆炸。网格生成要保证单元质量
  • 隐式求解不收敛：刚度太大或时间步太大。用更多的 CG 迭代，或阻尼
  • 体积锁定：ν\nuν 接近 0.5 时物体变硬板。降低λ\lambdaλ 或用混合单元
  • 单元反转（det⁡F<0\det F < 0detF<0）：形变太大导致单元翻面 → 力的方向错乱 → 爆炸。用 Neo-Hookean 或限制最大形变
  • 极分解的开销：每个单元一步 SVD。可以用迭代法或查表加速
  • 边界条件：固定点要正确处理（invMass = 0），否则会被慢慢拉走
  • 能量不守恒：隐式积分会引入数值阻尼（物体会"变懒"）。这是隐式的固有代价，通常可接受
  • 自碰撞：柔体（尤其布料）的自碰撞O(n2)O(n^2)O(n2)，实时很难，通常需要空间哈希 + 只检测局部
