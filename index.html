About

I'm Jundou Jiang (often called Davids), a game client engineer at Tencent Tianmei T1 Studio, working on core gameplay and the UGC platform of DreamStar.

Before games, I built core algorithms for a commercial CAE pre-processor — geometry editing, automatic mesh generation and mesh quality checking — and my graduate work applied deep learning to flow field prediction and mesh generation, inside the State Key Laboratory of Numerical Simulation for Engineering.

One thread runs through it all — I like making expensive, slow engineering computation fast enough to live inside real products, whether that is a solver, an editor, or a gameplay system. Lately that means Lua scripting and ability tooling for Unreal Engine, and smaller models that make researchers more effective.

UnLuaNova

Early refactor

A Lua scripting solution for Unreal Engine

Community continuation of Tencent/UnLua. Generates static binding tables for declared types to bypass the reflection hot path; ships Luau / Lua 5.5 backends; adds a CPU profiler written into Unreal Insights, a headless debug service, sandboxing and an infinite-loop watchdog.

UEAbilityKit

M0–M4 landed

Data-driven ability editor built on UE5 and GAS

Abilities are authored on a timeline — one ability is one timeline plus a set of tracks (Montage / GameplayEffect / GameplayCue / collision / displacement / branching), and everything lands on GAS primitives at runtime. Assets export to text for Git, logic and presentation stay separated.

A self-developed Hexo theme that fuses a personal homepage with a wiki-style knowledge base. A directory-tree engine turns hundreds of Markdown notes into a browsable tree with search, theme partitions, deep/light modes, KaTeX and Mermaid — the theme that powers this site.
