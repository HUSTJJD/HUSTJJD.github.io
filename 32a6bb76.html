刚体

Base Knowledge, Computer Graphics, Simulation 2025-08-10 2026-10-10 4629 字

刚体的自由度

刚体（Rigid Body）：形状不变，只有位置和朝向会变。

维度2D3D
平移23
旋转1（角度θ\thetaθ）3（四元数 / 旋转矩阵）
合计36

关键区别（对比柔体）：柔体有成千上万个自由度，刚体永远只有 6 个。这让刚体仿真便宜得多。

状态量

x=(cq),v=(vω)\mathbf{x} = \begin{pmatrix} \mathbf{c} \\ \mathbf{q} \end{pmatrix}, \quad \mathbf{v} = \begin{pmatrix} \mathbf{v} \\ \boldsymbol{\omega} \end{pmatrix}x=(cq​),v=(vω​)

符号含义
c\mathbf{c}c质心位置
q\mathbf{q}q朝向（四元数）
v\mathbf{v}v线速度
ω\boldsymbol{\omega}ω角速度（3D 是向量，方向 = 旋转轴，长度 = 角速度）

旋转的表示

表示优点缺点
四元数无奇点、紧凑（4 个数）、插值好（slerp）不直观、双重覆盖（qqq 和−q-q−q 相同）
旋转矩阵直接用于变换9 个数、需重新正交化
欧拉角直观万向锁（Gimbal Lock）

仿真中用四元数存朝向，需要变换时转成矩阵。

四元数的积分

q˙=12ω⊗q\dot{\mathbf{q}} = \frac{1}{2} \boldsymbol{\omega} \otimes \mathbf{q}q˙​=21​ω⊗q

其中ω\boldsymbol{\omega}ω 写成纯四元数(0,ωx,ωy,ωz)(0, \omega_x, \omega_y, \omega_z)(0,ωx​,ωy​,ωz​)。

// 更新朝向
Quaternion dq = Quaternion(0, w.x, w.y, w.z) * q * 0.5f;
q = normalize(q + dt * dq);

必须归一化：积分会引入误差，四元数不再是单位长度 → 变换会缩放物体。

角速度为什么不是"朝向的导数"

这是最容易搞混的地方：

q˙=12ω⊗q不是q˙=ω\dot{\mathbf{q}} = \frac{1}{2}\boldsymbol{\omega}\otimes\mathbf{q} \quad \text{不是} \quad \dot{\mathbf{q}} = \boldsymbol{\omega}q˙​=21​ω⊗q不是q˙​=ω

原因是四元数空间是弯曲的（单位四元数构成一个球面）。角速度是"切空间"的量。

转动惯量

惯性张量

I=∫ρ(r)(∥r∥21−rrT)dV\mathbf{I} = \int \rho(\mathbf{r})\left(\|\mathbf{r}\|^2\mathbf{1} - \mathbf{r}\mathbf{r}^T\right) dVI=∫ρ(r)(∥r∥21−rrT)dV

3×3 对称正定矩阵。对角化后的三个特征值叫主惯性矩。

物理意义：抵抗旋转的"转动质量"。

绕不同轴旋转，阻力不同:

     ┌───┐
     │   │   细长杆
     │   │   绕长轴转:  容易（I 小）
     │   │   绕横轴转:  困难（I 大）
     └───┘

世界空间的惯性张量

惯性张量是物体空间的常量，但计算要在世界空间：

Iworld−1=R Ibody−1 RT\mathbf{I}_{world}^{-1} = \mathbf{R}\,\mathbf{I}_{body}^{-1}\,\mathbf{R}^TIworld−1​=RIbody−1​RT

每帧都要更新（因为R\mathbf{R}R 在变）。实践中通常预计算Ibody−1\mathbf{I}_{body}^{-1}Ibody−1​ 并只做这个相似变换。

常见形状的惯性张量

形状惯性张量（主轴）
实心球（半径rrr，质量mmm）25mr2\frac{2}{5}mr^252​mr2（三轴相同）
长方体（边长a,b,ca,b,ca,b,c）m12(b2+c2), m12(a2+c2), m12(a2+b2)\frac{m}{12}(b^2+c^2),\ \frac{m}{12}(a^2+c^2),\ \frac{m}{12}(a^2+b^2)12m​(b2+c2), 12m​(a2+c2), 12m​(a2+b2)
细杆（长LLL，绕中心垂直轴）112mL2\frac{1}{12}mL^2121​mL2
圆柱12mr2\frac{1}{2}mr^221​mr2（轴向）、112m(3r2+h2)\frac{1}{12}m(3r^2+h^2)121​m(3r2+h2)（横向）

游戏中的做法：通常由碰撞形状（凸包/Box）计算，或用近似的解析公式。

动力学

牛顿-欧拉方程

mv˙=fIω˙+ω×(Iω)=τ\begin{aligned} m\dot{\mathbf{v}} &= \mathbf{f} \\ \mathbf{I}\dot{\boldsymbol{\omega}} + \boldsymbol{\omega} \times (\mathbf{I}\boldsymbol{\omega}) &= \boldsymbol{\tau} \end{aligned}mv˙Iω˙+ω×(Iω)​=f=τ​

第二项ω×(Iω)\boldsymbol{\omega} \times (\mathbf{I}\boldsymbol{\omega})ω×(Iω) 是陀螺项——这是刚体旋转特有的，也是它有趣的地方。

力矩

τ=(r−c)×f\boldsymbol{\tau} = (\mathbf{r} - \mathbf{c}) \times \mathbf{f}τ=(r−c)×f

力作用在质心以外的地方时，不只产生平移，还产生旋转。

void applyForce(RigidBody& b, vec3 force, vec3 point) {
    b.force += force;
    b.torque += cross(point - b.centerOfMass, force);
}

这就是为什么"推门把手"而不是"推门轴"——力臂越长力矩越大。

角动量

L=Iω\mathbf{L} = \mathbf{I}\boldsymbol{\omega}L=Iω

无外力矩时角动量守恒（但角速度不一定守恒，因为I\mathbf{I}I 随朝向变）。

这正是"陀螺不倒"和"猫翻正"的物理：通过改变I\mathbf{I}I（改变姿态）来改变ω\boldsymbol{\omega}ω，而L\mathbf{L}L 保持不变。

Dzhanibekov 效应（网球拍定理）：绕中间轴旋转不稳定——绕最大和最小惯性矩的轴旋转稳定，绕中间轴旋转会翻滚。

时间积分

void step(RigidBody& b, float dt) {
    // 1. 线速度
    b.v += dt * b.force / b.mass;

    // 2. 角速度（含陀螺项）
    vec3 Iw = b.I_world() * b.w;
    b.w += dt * b.I_world_inv() * (b.torque - cross(b.w, Iw));

    // 3. 位置
    b.x += dt * b.v;

    // 4. 朝向（四元数积分）
    b.q = normalize(b.q + dt * 0.5f * Quaternion(0, b.w) * b.q);

    // 清理
    b.force = b.torque = vec3(0);
}

陀螺项可以省略吗：对低速旋转影响不大，很多游戏引擎会省略（用Iω˙=τ\mathbf{I}\dot{\omega} = \tauIω˙=τ）。但高速旋转的物体（陀螺、抛出的球拍）会有明显差异。

碰撞响应

冲量法（Impulse-based）

碰撞是瞬时的，用冲量而不是力。

j=jn\mathbf{j} = j \mathbf{n}j=jn

其中n\mathbf{n}n 是碰撞法线，jjj 是冲量大小。

推导（两个刚体）

设相对速度在接触点：

vrel=(vA+ωA×rA)−(vB+ωB×rB)\mathbf{v}_{rel} = (\mathbf{v}_A + \boldsymbol{\omega}_A \times \mathbf{r}_A) - (\mathbf{v}_B + \boldsymbol{\omega}_B \times \mathbf{r}_B)vrel​=(vA​+ωA​×rA​)−(vB​+ωB​×rB​)

法向分量vn=vrel⋅nv_n = \mathbf{v}_{rel} \cdot \mathbf{n}vn​=vrel​⋅n（<0< 0<0 表示正在接近）。

有效质量（考虑旋转的贡献）：

1meff=1mA+1mB+nT[IA−1(rA×n)×rA]+nT[IB−1(rB×n)×rB]\frac{1}{m_{eff}} = \frac{1}{m_A} + \frac{1}{m_B} + \mathbf{n}^T\left[\mathbf{I}_A^{-1}(\mathbf{r}_A \times \mathbf{n}) \times \mathbf{r}_A\right] + \mathbf{n}^T\left[\mathbf{I}_B^{-1}(\mathbf{r}_B \times \mathbf{n}) \times \mathbf{r}_B\right]meff​1​=mA​1​+mB​1​+nT[IA−1​(rA​×n)×rA​]+nT[IB−1​(rB​×n)×rB​]

冲量大小（恢复系数eee，0 = 完全非弹性，1 = 完全弹性）：

j=−(1+e)vn1/meffj = \frac{-(1+e)v_n}{1/m_{eff}}j=1/meff​−(1+e)vn​​

void resolveCollision(Body& A, Body& B, vec3 n, vec3 p, float e) {
    vec3 rA = p - A.x, rB = p - B.x;
    vec3 vA = A.v + cross(A.w, rA);
    vec3 vB = B.v + cross(B.w, rB);
    vec3 vRel = vA - vB;
    float vn = dot(vRel, n);
    if (vn > 0) return;                    // 已经在分离

    float invMassSum = A.invM + B.invM
        + dot(n, cross(A.I_inv() * cross(rA, n), rA))
        + dot(n, cross(B.I_inv() * cross(rB, n), rB));

    float j = -(1 + e) * vn / invMassSum;

    A.v += j * A.invM * n;
    A.w += A.I_inv() * cross(rA, j * n);
    B.v -= j * B.invM * n;
    B.w -= B.I_inv() * cross(rB, j * n);
}

关键：旋转的贡献通过I−1(r×n)×r\mathbf{I}^{-1}(\mathbf{r} \times \mathbf{n}) \times \mathbf{r}I−1(r×n)×r 体现——这就是为什么"打在质心上不转，打在边上会转"。

摩擦

库仑摩擦模型：切向冲量受法向冲量限制。

jt=min⁡(μjn, −vt1/mefft)j_t = \min\left(\mu j_n,\ \frac{-v_t}{1/m_{eff}^t}\right)jt​=min(μjn​, 1/mefft​−vt​​)

μ\muμ 是摩擦系数。

vec3 t = normalize(vRel - vn * n);        // 切向方向
float jt = -dot(vRel, t) / invMassT;
jt = clamp(jt, -mu * j, mu * j);          // 关键：受法向冲量限制
// 应用切向冲量

"受法向冲量限制"是关键：这就是"压得越紧越难滑动"。

静止接触（Resting Contact）

问题：物体静止在地面上时，每帧都有微小的穿透 → 反复施加冲量 → 抖动（jitter）。

解法：

方法做法
位置修正（Baumgarte）加一个"把穿透推出来"的偏置项，带松弛系数β≈0.2\beta \approx 0.2β≈0.2
穿透容差（slop）允许 0.01~0.05 的穿透，超过才修正
速度阈值低速时不施加弹性冲量（只做位置修正）
休眠（Sleeping）低速持续一段时间就让物体休眠，不再模拟
// Baumgarte 稳定化
float bias = beta / dt * max(0, penetration - slop);
float j = (-(1+e)*vn + bias) / invMassSum;

休眠机制非常重要：没有它，堆在一起的箱子会永远微微抖动，且浪费大量 CPU。

迭代求解器（Sequential Impulse）

多个接触点互相影响（箱子四角同时接触地面），单次求解不够。

迭代若干次（4~20）:
  for 每个接触约束:
      计算当前相对速度
      施加冲量修正
下一轮会看到上一轮的效果 → 收敛

这是约束求解的标准方法（Box2D、Bullet、PhysX 都用它）。

配合 warm starting（用上一帧的冲量作为初值）可以大幅加速收敛——这是让堆叠稳定的关键技巧。

关节（Joint / Constraint）

关节约束
球铰（Ball）两点重合
铰链（Hinge）重合 + 旋转轴固定
滑轨（Slider）只沿一个轴移动
固定（Fixed）相对位置朝向全固定
距离（Distance）距离固定

求解：用同样的冲量迭代法（约束就是"某个量必须为 0"）。

布娃娃（Ragdoll）：一堆刚体用关节连起来。这是刚体仿真最经典的应用之一（角色死亡时的物理表现）。

工程实践

固定时间步 + 累加器

float accumulator = 0;
void update(float frameTime) {
    accumulator += frameTime;
    while (accumulator >= fixedDt) {
        stepPhysics(fixedDt);
        accumulator -= fixedDt;
    }
    // 渲染时用插值，避免抖动
    float alpha = accumulator / fixedDt;
    renderState = lerp(prevState, currState, alpha);
}

固定时间步是必须的：可变的Δt\Delta tΔt 让行为不确定（回放、网络同步需要确定性）。

性能

刚体的成本主要来自:
  1. 碰撞检测（宽相 + 窄相）
  2. 约束求解迭代

典型: 1000 个刚体，60 FPS，占 2~5 ms

优化：

  • 宽相用空间划分（BVH、网格、SAP）
  • 休眠静止物体（最有效）
  • 岛屿（island）划分：不互相接触的物体组独立求解

常见坑

  • 四元数没归一化：物体会慢慢变大或变小
  • 混淆角速度和朝向导数：q˙=12ωq\dot{q} = \frac{1}{2}\omega qq˙​=21​ωq，不是ω\omegaω
  • 惯性张量用错了空间：物体空间的I\mathbf{I}I 要经RIRT\mathbf{R}\mathbf{I}\mathbf{R}^TRIRT 变换
  • 冲量施加方向搞反：法线方向决定谁加谁减
  • 旋转的贡献忘了：只用质量算冲量 → 物体不会转（打在边缘也不转）
  • 摩擦没有受法向限制：会出现"越滑越快"
  • 静止抖动：需要 slop + Baumgarte + 休眠三件套
  • 堆叠不稳定：迭代次数不够，或没有 warm starting
  • 隧穿（tunneling）：高速物体一帧穿过薄墙。用 CCD（连续碰撞检测）或限制最大速度
  • 质心不在几何中心：不规则形状的质心要用积分算，用错会导致旋转行为诡异
  • 自由落体时的重力力矩：重力作用在质心，不产生力矩（不要对每个顶点施加重力）
