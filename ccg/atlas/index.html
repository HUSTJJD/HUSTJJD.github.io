计算共形几何全景知识地图：28 个模块与完整理论边界

Base Knowledge, Mathematics, 计算共形几何, 00 课程地图 2026-10-12 2026-10-11 2926 字
# David Gu# 学习路线# 知识图谱

这张图解决什么问题

计算共形几何不是“复分析 + 网格参数化”两门课的拼接。完整体系横跨：

  • 数学逻辑、线性代数、实分析、复分析和数值优化；
  • 代数拓扑、微分拓扑、黎曼几何和几何偏微分方程；
  • 黎曼面、Teichmüller 理论、代数曲线和双曲几何；
  • 计算拓扑、离散微分几何、计算几何和网格生成；
  • 三维获取、几何处理、最优输运、医学成像和几何深度学习。

主干课程的 10 个模块负责第一次系统学习，本页则把知识边界扩展到 28 个模块。已写成的 84 个短课统一放在主干课程；新增 18 个模块统一放在扩展课程，先建立详细逐课提纲，再按依赖顺序扩写。旧版长文只保留在参考讲义，不再与正式课程混排。

flowchart TB

00 → F01 → F02 → F03 → F04 → 01 → 02 → 03 → 04 → 05 → 06

重点是拓扑预检、稀疏线性系统、翻转控制、方向场和质量保证。

路线 C：黎曼面与理论研究

F01 → F03 → F04 → 01 → T02 → 02 → 03 → G03 → 04
→ C05 → C06 → 07 → R02 → C07 → 08

这条路线覆盖从 de Rham/Hodge 到 Abel-Jacobi、Riemann-Roch 和 Teichmüller 空间的理论链。

路线 D：几何深度学习与生成模型

F02 → F03 → F05 → 01 → 03 → 05 → 09 → O02 → A01

重点不是把共形几何当作网络装饰，而是理解内在度量、谱算子、输运距离与等变性的数学来源。

十组核心理论问题

完整学习后，应能回答以下问题，而不只是记住定理名称：

  1. 局部坐标为何能定义与坐标无关的切向量和微分形式？
  2. 基本群、同调、de Rham 上同调和 Hodge 调和代表分别保留什么信息？
  3. Gauss 曲率为何既可由嵌入弯曲定义，又是内在量？
  4. Gauss-Bonnet、Poincaré-Hopf 和 Euler 类为何是同一个局部到整体现象的不同版本？
  5. 全纯、调和、共形和拟共形在二维中怎样互相联系，又在哪些条件下不能互推？
  6. 一致化定理为何把所有单连通黎曼面归到球面、平面和双曲圆盘？
  7. 周期矩阵、Jacobian variety、除子和 Riemann-Roch 怎样控制高亏格曲面的全局函数？
  8. 连续能量、弱形式、有限元矩阵和离散几何算法之间怎样逐步对应？
  9. 离散 Ricci 流、Koebe 迭代和调和映射各自改变什么，保证什么，不保证什么？
  10. 最优输运、共形标准化和几何深度学习为何不能互相替代，却可以组成同一管线？

教学笔记的统一完成标准

“收录了一个术语”不算完成。一篇正式短课必须同时具备：

  1. 前置知识：读者缺什么应能退回准确页面；
  2. 几何直觉：先回答对象解决了什么问题；
  3. 严格定义：写清定义域、值域、正则性和方向约定；
  4. 逐步推导：等号之间不跳关键步骤；
  5. 最小例子：至少一个可以手算到底的例子；
  6. 反例与边界：说明假设为何不能删；
  7. 离散对应：连续对象落在顶点、边、面还是矩阵；
  8. 代码实验：输入、输出、断言和失败模式完整；
  9. 验证方法：残差、不变量、畸变和收敛分开检查；
  10. 带答案自测：不能只列开放问题。
