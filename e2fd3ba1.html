自动关联目录：最优输运与几何深度学习

本页是集中复习用的长篇参考。第一次学习请进入 模块 9：最优输运与几何深度学习，按 8 个单概念短课阅读。

本章目标

共形映射主要控制角度，最优输运主要控制质量守恒。两者结合可以把曲面先标准化到公共参数域，再以最小代价匹配面积、密度或概率分布。

本章目标：

  1. 区分 Monge 映射与 Kantorovich 输运计划；
  2. 推导线性规划原始/对偶形式；
  3. 理解 Wasserstein 距离、Brenier 定理与 Monge–Ampère 方程；
  4. 理解离散熵正则与 Sinkhorn 迭代；
  5. 说明共形几何、最优输运和几何深度学习各自解决什么，而不是把它们混成一个流行词列表。

1. 从“点对应”到“质量输运”

设源空间XXX 上有概率测度μ\muμ，目标空间YYY 上有概率测度ν\nuν。代价函数

c:X×Y→Rc:X\times Y\to\mathbb Rc:X×Y→R

表示把单位质量从xxx 移到yyy 的成本。

传统点云最近邻只关心局部距离，不保证目标每个区域接收到正确质量。最优输运要求整体质量守恒。

2. Monge 问题

寻找映射T:X→YT:X\to YT:X→Y，使推前测度

T#μ=ν,T_\#\mu=\nu,T#​μ=ν,

并最小化

inf⁡T#μ=ν∫Xc(x,T(x)),dμ(x).\boxed{ \inf_{T_\#\mu=\nu} \int_Xc(x,T(x)),d\mu(x). }T#​μ=νinf​∫X​c(x,T(x)),dμ(x).​

推前定义为

(T#μ)(B)=μ(T−1(B)).(T_\#\mu)(B)=\mu(T^{-1}(B)).(T#​μ)(B)=μ(T−1(B)).

若有密度且TTT 可微可逆，质量守恒写成 change-of-variables：

ρμ(x)=ρν(T(x))∣det⁡DT(x)∣.\rho_\mu(x) =\rho_\nu(T(x))|\det DT(x)|.ρμ​(x)=ρν​(T(x))∣detDT(x)∣.

2.1 Monge 问题的困难

  • 可行映射可能不存在：一个原子不能被映射拆成两份；
  • 约束T#μ=νT_\#\mu=\nuT#​μ=ν 非线性；
  • 映射空间不凸；
  • 极限映射可能需要“分裂质量”。

3. Kantorovich 松弛

用联合测度/输运计划π\piπ 代替确定映射。π(A×B)\pi(A\times B)π(A×B) 表示从AAA 运到BBB 的质量。要求边缘分布：

(PX)#π=μ,(PY)#π=ν.(P_X)_\#\pi=\mu, \qquad (P_Y)_\#\pi=\nu.(PX​)#​π=μ,(PY​)#​π=ν.

问题：

inf⁡π∈Π(μ,ν)∫X×Yc(x,y),dπ(x,y).\boxed{ \inf_{\pi\in\Pi(\mu,\nu)} \int_{X\times Y}c(x,y),d\pi(x,y). }π∈Π(μ,ν)inf​∫X×Y​c(x,y),dπ(x,y).​

Π(μ,ν)\Pi(\mu,\nu)Π(μ,ν) 是凸集，目标对π\piπ 线性，因此这是凸优化。

6. Wasserstein 距离

在度量空间(X,d)(X,d)(X,d) 上，取代价c(x,y)=d(x,y)pc(x,y)=d(x,y)^pc(x,y)=d(x,y)p：

满足有限ppp 阶矩时，WpW_pWp​ 是概率测度空间上的距离。

6.1 为什么它比逐点L2L^2L2 更懂几何

两个窄峰相距ϵ\epsilonϵ：逐点密度差可能几乎不变，但 Wasserstein 距离约为ϵ\epsilonϵ，因为它测量“质量移动多远”。

7.W1W_1W1​ 的 Kantorovich–Rubinstein 对偶

当c=dc=dc=d：

W1(μ,ν)=sup⁡∥f∥Lip≤1(∫f,dμ−∫f,dν).\boxed{ W_1(\mu,\nu) =\sup_{\|f\|_{Lip}\le1} \left(\int f,d\mu-\int f,d\nu\right). }W1​(μ,ν)=∥f∥Lip​≤1sup​(∫f,dμ−∫f,dν).​

WGAN 中的 critic 正是在近似 1-Lipschitz 势函数，但神经网络训练只是对偶优化的一个近似实现，并不自动得到精确 Wasserstein 距离。

8. 二次代价与 Brenier 定理

在Rn\mathbb R^nRn 中取

c(x,y)=12∥x−y∥2.c(x,y)=\frac12\|x-y\|^2.c(x,y)=21​∥x−y∥2.

若源测度μ\muμ 对 Lebesgue 测度绝对连续，则最优 Monge 映射几乎处处唯一，且存在凸函数uuu：

T(x)=∇u(x).\boxed{T(x)=\nabla u(x).}T(x)=∇u(x).​

这就是 Brenier 定理。

8.1 Monge–Ampère 方程

质量守恒：

ρμ(x)=ρν(∇u(x))detD2u(x).\rho_\mu(x) =\rho_\nu(\nabla u(x))det D^2u(x).ρμ​(x)=ρν​(∇u(x))detD2u(x).

因此凸势满足

det⁡D2u(x)=ρμ(x)ρν(∇u(x)).\boxed{ \det D^2u(x) =\frac{\rho_\mu(x)}{\rho_\nu(\nabla u(x))}. }detD2u(x)=ρν​(∇u(x))ρμ​(x)​.​

这是完全非线性 PDE。凸性是椭圆性和唯一性的关键条件，不能省略。

9. 半离散最优输运与凸几何

源μ\muμ 连续、目标

ν=∑i=1naiδyi\nu=\sum_{i=1}^na_i\delta_{y_i}ν=i=1∑n​ai​δyi​​

离散时，可优化高度hih_ihi​，定义 power/Laguerre cells：

Wi(h)={x:⟨x,yi⟩+hi≥⟨x,yj⟩+hj,∀j}.W_i(h)=\{x: \langle x,y_i\rangle+h_i \ge \langle x,y_j\rangle+h_j, \forall j\}.Wi​(h)={x:⟨x,yi​⟩+hi​≥⟨x,yj​⟩+hj​,∀j}.

希望每个 cell 质量满足

μ(Wi(h))=ai.\mu(W_i(h))=a_i.μ(Wi​(h))=ai​.

存在凸能量，其梯度为

∂E∂hi=μ(Wi(h))−ai.\frac{\partial E}{\partial h_i} =\mu(W_i(h))-a_i.∂hi​∂E​=μ(Wi​(h))−ai​.

Hessian 由相邻 cells 的公共边/面构成，适合 Newton 法。这正是“凸几何视角”的计算核心。

10. 熵正则与 Sinkhorn

对离散 OT 添加负熵正则：

min⁡P≥0⟨C,P⟩+ε∑ijPij(log⁡Pij−1)\min_{P\ge0} \langle C,P\rangle +\varepsilon\sum_{ij}P_{ij}(\log P_{ij}-1)P≥0min​⟨C,P⟩+εij∑​Pij​(logPij​−1)

满足相同边缘约束。最优解具有形式

P=diag⁡(u)Kdiag⁡(v),Kij=e−Cij/ε.P=\operatorname{diag}(u)K\operatorname{diag}(v), \qquad K_{ij}=e^{-C_{ij}/\varepsilon}.P=diag(u)Kdiag(v),Kij​=e−Cij​/ε.

边缘约束给出交替缩放：

u←a/(Kv),u\leftarrow a/(Kv),u←a/(Kv),

v←b/(KTu).v\leftarrow b/(K^Tu).v←b/(KTu).

这就是 Sinkhorn 迭代。

10.1 偏差与稳定性

  • ε\varepsilonε 大：更平滑、更快，但偏离原 OT；
  • ε\varepsilonε 小：更接近 OT，但KKK 下溢且迭代困难；
  • 实现应使用 log-domain stabilization；
  • regularized OT 有熵偏差，比较分布时可用 Sinkhorn divergence 消除自相似偏差。

11. 曲面上的代价

对曲面数据，代价选择决定匹配的几何含义：

代价优点问题
三维欧氏距离易算会穿过薄壳，忽略曲面内在结构
曲面测地距离内在全对全计算昂贵
heat/geodesic 近似可扩展有离散与时间尺度误差

谱嵌入距离对噪声可稳定截断和重特征值导致不唯一

12. 共形几何与最优输运如何配合

它们解决不同畸变：

  • 共形映射消除复杂拓扑/几何域，保局部角度；
  • 最优输运在公共域中匹配面积或概率质量。

一个典型流程：

flowchart LR
    M[曲面 M] -->|一致化| DM[标准域 D_M]
    N[曲面 N] -->|一致化| DN[标准域 D_N]
    DM -->|Möbius/标记点归一化| D[公共标准域]
    DN -->|Möbius/标记点归一化| D
    D -->|最优输运匹配密度| T[质量保持映射]
    T -->|拉回| F[M 到 N 的配准]

仅做共形映射会有面积畸变；追加 OT 可校正密度，但组合后通常不再共形。这是多目标取舍，不是“同时完美”。

13. 几何深度学习中的三类结构

13.1 图 Laplacian 与谱卷积

离散 Laplace–Beltrami 广义特征问题：

Lϕk=λkMϕk.L\phi_k=\lambda_kM\phi_k.Lϕk​=λk​Mϕk​.

特征函数是曲面上的 Fourier 基。谱滤波：

y=g(Δ)x≈∑k=0K−1g(λk)⟨x,ϕk⟩Mϕk.y=g(\Delta)x \approx\sum_{k=0}^{K-1}g(\lambda_k) \langle x,\phi_k\rangle_M\phi_k.y=g(Δ)x≈k=0∑K−1​g(λk​)⟨x,ϕk​⟩M​ϕk​.

问题：不同曲面的特征基可能有符号、旋转和重特征空间不唯一，不能直接逐列对齐。

13.2 内在消息传递

图神经网络

hi(l+1)=Φ(hi(l),Agg⁡j∈N(i)Ψ(hi(l),hj(l),eij))h_i^{(l+1)} =\Phi\left(h_i^{(l)}, \operatorname{Agg}_{j\in N(i)} \Psi(h_i^{(l)},h_j^{(l)},e_{ij}) \right)hi(l+1)​=Φ(hi(l)​,Aggj∈N(i)​Ψ(hi(l)​,hj(l)​,eij​))

若eije_{ij}eij​ 使用测地距离、角度、平行移动等内在量，可减少对三维刚体姿态和网格嵌入的依赖。

但普通 message passing 只保证顶点置换等变，不自动保证旋转、Möbius 或重新参数化等变。

13.3 测度损失与生成模型

OT 可用于：

  • 点云分布匹配；
  • 形状生成的分布损失；
  • domain adaptation；
  • 特征分布对齐；
  • unbalanced OT 处理质量不等或局部缺失。

需要区分：精确 OT、熵正则 OT、sliced Wasserstein、Chamfer distance 并不是同一个量。

14. 共形结构在神经网络中的作用边界

共形几何可提供：

  1. canonical domain：把不同形状映到球面、平面或双曲域；
  2. 角度稳定的局部坐标：定义卷积核方向；
  3. 内在 Laplacian：谱特征和扩散算子；
  4. Beltrami 场：把形变编码成空间分布的各向异性；
  5. 曲率和拓扑特征：跨网格分辨率的几何信号。

它不能自动解决：

  • 语义对应；
  • 对称形状上的唯一规范化；
  • 不同拓扑间的双射；
  • 噪声/缺失导致的拓扑错误；
  • 离散化改变后的跨网格泛化。

15. Python：Sinkhorn 教学实现

import numpy as np


def sinkhorn(a, b, cost, epsilon=0.05, max_iter=5000, tol=1e-9):
    """教学实现；小 epsilon 时应改用 log-domain 版本。"""
    a = np.asarray(a, dtype=float)
    b = np.asarray(b, dtype=float)
    C = np.asarray(cost, dtype=float)

    if not np.isclose(a.sum(), b.sum()):
        raise ValueError("source and target mass must match")
    if np.any(a < 0) or np.any(b < 0):
        raise ValueError("mass must be nonnegative")

    K = np.exp(-C / epsilon)
    u = np.ones_like(a)
    v = np.ones_like(b)

    for iteration in range(max_iter):
        old_u = u.copy()
        u = a / np.maximum(K @ v, 1e-300)
        v = b / np.maximum(K.T @ u, 1e-300)
        if np.max(np.abs(u - old_u)) < tol:
            break

    P = u[:, None] * K * v[None, :]
    row_error = np.max(np.abs(P.sum(axis=1) - a))
    col_error = np.max(np.abs(P.sum(axis=0) - b))
    return P, {
        "iterations": iteration + 1,
        "cost": float(np.sum(P * C)),
        "row_error": float(row_error),
        "col_error": float(col_error),
    }

这个实现容易下溢。工程版应维护对偶 log-potentials：

fi=εlog⁡ui,gj=εlog⁡vj,f_i=\varepsilon\log u_i, \qquad g_j=\varepsilon\log v_j,fi​=εlogui​,gj​=εlogvj​,

并用 logsumexp 更新。

16. 研究/工程检查表

使用 OT 损失时必须报告：

  • 代价ccc 的定义与单位；
  • 是否精确 OT、熵正则、unbalanced 或 sliced 近似；
  • ε\varepsilonε 与迭代停止条件；
  • 边缘残差；
  • 点数/网格分辨率变化下的稳定性；
  • 是否对输入质量归一化；
  • 梯度是否穿过迭代求解器，采用何种隐式/展开求导；
  • 与 Chamfer、Hausdorff、普通L2L^2L2 的对照实验。

使用共形参数域时还要报告：

  • Möbius 自由度如何固定；
  • 切缝和奇点位置；
  • 共形/面积畸变分布；
  • 不同 triangulation 下结果是否稳定。
