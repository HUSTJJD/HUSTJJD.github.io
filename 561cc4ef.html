本页是集中复习用的长篇参考。第一次学习请进入 模块 2：微分形式与 Hodge 理论，按 9 个单概念短课阅读。

本章目标

向量分析把梯度、旋度和散度写成三个看似不同的算子；微分形式把它们统一成一个外微分ddd。Hodge 理论再加入度量，把每个微分形式正交分解为恰当、余恰当和调和三部分。

本章学完后，你应当能够：

  1. 从曲线等价类定义切向量，从切向量的对偶定义 1-形式；
  2. 计算楔积、拉回和外微分；
  3. 用广义 Stokes 定理统一微积分基本定理、Green、Gauss 和 Stokes 公式；
  4. 理解 de Rham 上同调如何检测曲面的洞；
  5. 推导 Hodge 星、余微分和 Hodge-Laplacian；
  6. 把连续 Hodge 分解写成三角网格上的稀疏线性系统。

1. 切空间：曲面上允许的瞬时运动

1.1 用曲线定义切向量

设MMM 是光滑曲面，p∈Mp\in Mp∈M。所有经过ppp 的光滑曲线γ:(−ϵ,ϵ)→M\gamma:(-\epsilon,\epsilon)\to Mγ:(−ϵ,ϵ)→M 满足γ(0)=p\gamma(0)=pγ(0)=p。

ddt∣t=0(φ∘γ1)(t)=ddt∣t=0(φ∘γ2)(t),\left.\frac{d}{dt}\right|_{t=0}(\varphi\circ\gamma_1)(t) = \left.\frac{d}{dt}\right|_{t=0}(\varphi\circ\gamma_2)(t),dtd​​t=0​(φ∘γ1​)(t)=dtd​​t=0​(φ∘γ2​)(t),

{∂∂u1,∂∂u2},\left\{\frac{\partial}{\partial u^1}, \frac{\partial}{\partial u^2}\right\},{∂u1∂​,∂u2∂​},

3. 外代数与微分形式

3.1 楔积

两个 1-形式的楔积满足反对称性

α∧β=−β∧α.\alpha\wedge\beta=-\beta\wedge\alpha.α∧β=−β∧α.

所以

du∧du=0,dv∧du=−du∧dv.du\wedge du=0, \qquad dv\wedge du=-du\wedge dv.du∧du=0,dv∧du=−du∧dv.

若

α=a1du+a2dv,β=b1du+b2dv,\alpha=a_1du+a_2dv, \qquad \beta=b_1du+b_2dv,α=a1​du+a2​dv,β=b1​du+b2​dv,

α∧β=(a1b2−a2b1)du∧dv.\alpha\wedge\beta =(a_1b_2-a_2b_1)du\wedge dv.α∧β=(a1​b2​−a2​b1​)du∧dv.

17. Python：验证离散复形

import numpy as np


def verify_complex(B1, B2, atol=1e-12):
    defect = B1 @ B2
    max_abs = 0.0 if defect.nnz == 0 else np.abs(defect.data).max()
    if max_abs > atol:
        raise ValueError(f"boundary of boundary is not zero: {max_abs}")
    return max_abs


def exact_projection(d0, star1, omega, anchor=0):
    # 解 d0^T star1 d0 f = d0^T star1 omega。
    # 删除一个自由度消除常数零空间。
    from scipy.sparse.linalg import spsolve

    L = d0.T @ star1 @ d0
    rhs = d0.T @ star1 @ omega
    keep = np.arange(L.shape[0]) != anchor
    f = np.zeros(L.shape[0])
    f[keep] = spsolve(L[keep][:, keep].tocsr(), rhs[keep])
    return d0 @ f, f
