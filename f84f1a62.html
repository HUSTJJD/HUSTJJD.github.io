实时阴影

Base Knowledge, Computer Graphics, Rendering 2025-08-10 2026-10-10 4174 字

shadow mapping

基本思路

阴影 = 从光源看不到，但从相机看得到的地方。

Pass 1: 从光源渲染深度图（shadow map），只存深度
Pass 2: 从相机渲染，对每个片元：
        - 把它变换到光源空间，得到 (x, y, z_light)
        - 采样 shadow map 得到该位置的最浅深度 d
        - 若 z_light > d + bias → 被遮挡 → 在阴影里
float shadow = 0.0;
vec4 lightSpace = lightMatrix * worldPos;
vec3 proj = lightSpace.xyz / lightSpace.w;      // 透视除法
proj = proj * 0.5 + 0.5;                        // [-1,1] → [0,1]

float closest = texture(shadowMap, proj.xy).r;
float current = proj.z;
shadow = (current > closest + bias) ? 1.0 : 0.0;

问题与解法

1. 自阴影 / 阴影痤疮（Shadow Acne）

原因：shadow map 是离散的，一个纹素覆盖一片区域，深度比较会有误差 → 表面自己遮挡自己。

  光源
   │\  │\  │\
───┴───┴───┴───  表面（真实）
    采样点的深度 vs 存储的深度 → 有误差 → 部分被判为遮挡

解法 A：常数 bias

float bias = 0.005;

简单，但 bias 太大会漏光（peter-panning）——阴影和物体脱离。

解法 B：斜率缩放 bias（slope-scaled bias）

float bias = max(0.05 * (1.0 - dot(normal, lightDir)), 0.005);

表面越斜（相对光线），需要的 bias 越大。

解法 C：法线偏移（normal offset）

vec3 offsetPos = worldPos + normal * texelSize * 2.0;

沿着法线往外挪一点再采样，比沿光线方向挪更符合直觉，副作用小。

解法 D：正面剔除（front-face culling）

生成 shadow map 时只画背面（背面深度 = 物体"背面"的深度，一定比正面深）。

  • 不需要调 bias
  • 问题：薄物体（纸片）会出错；物体必须封闭

2. 走样（Aliasing）

shadow map 分辨率不够 → 阴影边缘锯齿。

方法做法
提高分辨率直接但贵
Cascaded Shadow Maps近处用高分辨率，远处用低（见下）
PCF采样多次并平均（见下）
Contact hardening / PCSS可变半径的软化

3. Peter-panning（浮空）

bias 太大导致阴影脱离物体，物体看起来"飘"着。这是 bias 的固有代价。

PCF（Percentage Closer Filtering）

不是过滤深度值，而是过滤比较结果。

关键区别:
  过滤深度:      depth = filter(shadowMap)  → 错误！会得到错误的遮挡关系
  PCF:           result = filter(depth > closest ? 1 : 0)  → 正确
float pcf(vec3 proj, vec2 texelSize, int radius) {
    float sum = 0.0;
    for (int x = -radius; x <= radius; x++)
        for (int y = -radius; y <= radius; y++) {
            float closest = texture(shadowMap, proj.xy + vec2(x,y) * texelSize).r;
            sum += (proj.z > closest + bias) ? 1.0 : 0.0;
        }
    return sum / float((2*radius+1) * (2*radius+1));
}

结果：软阴影边缘（但半径固定，不是物理正确的）。

Cascaded Shadow Maps（CSM）

问题：一个大 shadow map 覆盖整个场景 → 近处分辨率不够。

解法：按距离把视锥切成若干层，每层一个 shadow map。

近  ├─ Cascade 0 ─┤ 2048×2048，覆盖 0~10m
    ├─ Cascade 1 ─┤ 1024×1024，覆盖 10~30m
    ├─ Cascade 2 ─┤ 1024×1024，覆盖 30~100m
远  └─ Cascade 3 ─┘ 1024×1024，覆盖 100~500m
// 选择 cascade
int cascade = 0;
for (int i = 0; i < NUM_CASCADES; i++) {
    if (viewZ < cascadeSplits[i]) { cascade = i; break; }
}
vec4 lightSpace = lightMatrices[cascade] * worldPos;

关键细节：

  • 层间过渡：直接切换会有明显的接缝，要跨层混合
  • 分割位置：对数分割比均匀分割更合理（近处需要更细）
  • 稳定化：相机移动时 shadow map 会"抖动"（texel snapping 解决）

VSM（Variance Shadow Maps）

动机

PCF 需要多次采样，且不能预过滤（因为比较是非线性的）。

VSM 的思路：用概率/统计的方式估计"深度大于 d 的比例"，从而可以预过滤（用 mipmap、线性过滤）。

原理

存储深度的一阶矩和二阶矩：

M1=E[z],M2=E[z2]M_1 = E[z], \quad M_2 = E[z^2]M1​=E[z],M2​=E[z2]

方差：

σ2=M2−M12\sigma^2 = M_2 - M_1^2σ2=M2​−M12​

用 Chebyshev 不等式估计"深度 > d 的概率上界"：

P(z>d)≤σ2σ2+(d−M1)2,d>M1P(z > d) \le \frac{\sigma^2}{\sigma^2 + (d - M_1)^2}, \quad d > M_1P(z>d)≤σ2+(d−M1​)2σ2​,d>M1​

vec2 moments = texture(shadowMap, proj.xy).xy;
float mean = moments.x;
float variance = moments.y - moments.x * moments.x;
float d = proj.z - mean;
float pMax = variance / (variance + d * d);      // 遮挡概率（上界）
float shadow = (proj.z > mean) ? clamp(pMax, 0.0, 1.0) : 1.0;

关键优势：moments 可以线性过滤（mipmap、硬件双线性）→ 可以用低分辨率 shadow map + 硬件过滤，效果好且快。

问题：光渗（Light Bleeding）

当深度分布差异很大时，Chebyshev 上界过于保守 → 阴影变淡，出现"不该亮的地方亮了"。

缓解：

  • 限制 pMax 的下界（引入一个 "light bleeding reduction" 参数）
  • 用更高的矩（moment shadow maps）

moment shadow maps（MSM）

VSM 的推广：存储更多阶矩（4 阶甚至更高），用更复杂的分布拟合。

M1,M2,M3,M4(用 4 个通道)M_1, M_2, M_3, M_4 \quad \text{(用 4 个通道)}M1​,M2​,M3​,M4​(用 4 个通道)

原理：矩越多，对深度分布的刻画越准，Chebyshev 上界就越紧 → 光渗越少。

方法存储光渗性能
PCF深度无多次采样，慢
VSM2 矩明显快（可预过滤）
MSM (4 阶)4 矩少中

工程选择：PCF 仍是主流（质量可控），VSM/MSM 在特定场景（需要大幅软化、缓存友好）有优势。

PCSS（Percentage-Closer Soft Shadows）

物理观察：半影（penumbra）的大小取决于遮挡物到接收面的距离。

        光源（有大小）
       /            \
      /              \
  遮挡物 ──── w_light ────
     │                  \
     │ d_blocker          \
     │                      \
  接收面 ────────────────────  半影宽度 w_penumbra

相似三角形:
  w_penumbra / w_light = (d_receiver - d_blocker) / d_blocker

PCSS 三步：

1. Blocker Search:
   在 shadow map 上按半径采样，找出所有"遮挡者"的平均深度 d_blocker

2. Penumbra Estimation:
   w_penumbra = w_light * (d_receiver - d_blocker) / d_blocker

3. PCF:
   用 w_penumbra 作为 PCF 的滤波半径
float findBlocker(vec2 uv, float zReceiver, float searchRadius) {
    float sum = 0.0; int cnt = 0;
    for (/* 采样 N 次 */) {
        float d = texture(shadowMap, uv + offset).r;
        if (d < zReceiver) { sum += d; cnt++; }    // 是遮挡者
    }
    return cnt > 0 ? sum / cnt : -1.0;              // -1 = 没有遮挡者
}

float pcss(vec3 proj) {
    float blocker = findBlocker(proj.xy, proj.z, searchRadius);
    if (blocker < 0.0) return 1.0;                  // 全亮
    float penumbra = LIGHT_SIZE * (proj.z - blocker) / blocker;
    return pcf(proj, penumbra);
}

效果：接触处（blocker 靠近接收面）阴影锐利，远处柔和——这就是 contact hardening，符合物理。

代价：步骤 1 和 3 都要多次采样，很贵。优化：

  • 预生成半影估计图
  • 用随机采样 + 时域累积（现代做法）

SDF Shadows

SDF（Signed Distance Field）软阴影——用距离场做解析式的软阴影。

原理

从着色点ppp 沿光线方向lll 步进，记录"最窄的角度"：

沿光线走:  p → p + l*t1 → p + l*t2 → ...
每步:      sdf(p_i) = 到最近表面的距离
          角度 = asin(sdf(p_i) / t_i)
取所有步中最小的角度 → 半影大小
float sdfShadow(vec3 p, vec3 l) {
    float res = 1.0;
    float t = 0.05;                       // 起始偏移，避免自遮挡
    for (int i = 0; i < 64 && t < MAX_DIST; i++) {
        float d = sdf(p + l * t);
        if (d < 0.001) return 0.0;        // 打到东西了，全黑
        res = min(res, SHARPNESS * d / t); // 记录最窄的角度
        t += clamp(d, 0.01, 0.5);         // 安全步进（sphere tracing）
    }
    return clamp(res, 0.0, 1.0);
}

优缺点

优点缺点
天然软阴影，contact hardening 自动产生需要 SDF（生成/存储有代价）
不需要 shadow map（无分辨率问题）步进是循环，比一次纹理采样慢
阴影随距离自然变化SDF 精度有限时会有漏光/带状
适合程序化/稀疏场景复杂动态场景维护 SDF 昂贵

现代应用：UE5 的 Virtual Shadow Map + SDF 软阴影、Lumen 的 SDF 追踪。

各方法对比

方法软阴影接触硬化成本漏光
Hard Shadow Map✗—低—
PCF固定宽度✗中（多次采样）—
PCSS✓✓高—
VSM✓部分低（可预过滤）有
MSM✓部分中少
SDF✓✓中（步进）少
Ray Traced✓✓高（硬件 RT 可实时）无

常见坑

  • bias 调不动：太小明暗条纹（acne），太大浮空。用 slope-scaled bias 或 normal offset
  • PCF 过滤的是深度：错！必须过滤比较结果
  • CSM 的层间接缝：要在两层之间做混合，或用 "cascade blend" 区域
  • VSM 的深度溢出：存zzz 和z2z^2z2 时用 float16 精度不够，会出错。用 float32 或做归一化
  • PCSS 的 blocker search 半径：太大采样不足（噪声），太小漏掉遮挡物（阴影偏硬）
  • SDF 步进的起始偏移：太小会自遮挡（表面自己挡自己）
  • 点光源的 shadow map：要用 cube map 或 omnidirectional shadow map（6 个面，或用双抛物面）
  • 透明物体的阴影：shadow map 阶段要不要写深度？透明物体通常不投影（或单独处理）
  • 动态物体导致 shadow map 每帧重建：静态部分可以缓存（cache shadow map，只在光源/物体变化时更新）
