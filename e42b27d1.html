表面模型

Microfacet BRDF（ microfacet 微表面模型）

现代 PBR 的统一框架：表面由无数微小的镜面组成，宏观的反射是它们的统计结果。

fr(i,o)=F(i,h)⋅G(i,o,h)⋅D(h)4(n⋅i)(n⋅o)f_r(\mathbf{i}, \mathbf{o}) = \frac{F(\mathbf{i}, \mathbf{h}) \cdot G(\mathbf{i}, \mathbf{o}, \mathbf{h}) \cdot D(\mathbf{h})}{4(\mathbf{n}\cdot\mathbf{i})(\mathbf{n}\cdot\mathbf{o})}fr​(i,o)=4(n⋅i)(n⋅o)F(i,h)⋅G(i,o,h)⋅D(h)​

其中h=normalize(i+o)\mathbf{h} = \text{normalize}(\mathbf{i} + \mathbf{o})h=normalize(i+o) 是半程向量。

项名称含义
DDDNDF（法线分布函数）有多少微表面的法线朝向h\mathbf{h}h
GGG几何/遮蔽项微表面之间的自遮挡
FFFFresnel视角/材质决定的反射比例

分母的 4 是归一化因子（来自微表面投影面积的换算）。

GGX（Trowbridge-Reitz）

当前工业标准的 NDF：

D(h)=α2π((n⋅h)2(α2−1)+1)2D(\mathbf{h}) = \frac{\alpha^2}{\pi \big((\mathbf{n}\cdot\mathbf{h})^2 (\alpha^2 - 1) + 1\big)^2}D(h)=π((n⋅h)2(α2−1)+1)2α2​

其中α=roughness2\alpha = \text{roughness}^2α=roughness2（这个平方是 Disney 的改进，让 roughness 变化更线性）。

为什么 GGX 赢了 Beckmann/Phong：

Beckmann/Phong: 高光衰减很快，边缘"干净"
GGX:            有更长的"尾巴"（long tail）
                → 高光周围有一圈柔和的光晕
                → 更接近真实测量数据

验证：GGX 的预测和实测的金属/粗糙表面数据吻合最好。

Smith 遮蔽项（配合 GGX）：

G(i,o)=G1(i)⋅G1(o),G1(v)=2(n⋅v)(n⋅v)+α2+(1−α2)(n⋅v)2G(\mathbf{i},\mathbf{o}) = G_1(\mathbf{i}) \cdot G_1(\mathbf{o}), \quad G_1(\mathbf{v}) = \frac{2(\mathbf{n}\cdot\mathbf{v})}{(\mathbf{n}\cdot\mathbf{v}) + \sqrt{\alpha^2 + (1-\alpha^2)(\mathbf{n}\cdot\mathbf{v})^2}}G(i,o)=G1​(i)⋅G1​(o),G1​(v)=(n⋅v)+α2+(1−α2)(n⋅v)2​2(n⋅v)​

能量守恒的改进：Smith 模型忽略了"被遮挡后重新弹出来的光"。现代实现会用 Smith + 多次散射补偿（如 UE 的 MultiScatterApprox），否则粗糙金属会偏暗（能量损失可达 30%）。

Disney Principled BRDF

Burley 2012（SIGGRAPH），为美术友好而设计。

设计原则：

  1. 参数应该直观（不是物理量）
  2. 参数尽可能少
  3. 参数范围 0~1
  4. 允许合理外推（极端值也不能出错）
  5. 鲁棒

参数：

参数含义
baseColor基础色
subsurface次表面（漫反射形状）
metallic金属度
specular镜面强度（非金属的F0F_0F0​）
roughness粗糙度
specularTint高光染色
anisotropic各向异性
sheen织物绒毛
clearcoat清漆（车漆的第二层）

影响：UE4、Blender、Filament、Unity 的材质模型都源自它。"Metallic-Roughness" 工作流就是它的简化。

Metallic vs Specular 工作流：

Metallic-RoughnessSpecular-Glossiness
参数baseColor, metallic, roughnessdiffuse, specular, glossiness
更直观✓✗
更灵活✗✓
glTF 标准✓（扩展）

Metallic 的隐含约束：金属没有漫反射，albedo 全部进入F0F_0F0​（有颜色）；非金属F0F_0F0​ 固定约 0.04（无色）。这个约束避免了不物理的材质（这正是它被选为标准的原因）。

LTC（Linearly Transformed Cosines）

问题：用多边形面光源（area light）照亮光泽表面的解析解。

∫Pfr(i,o)cos⁡θi di\int_{P} f_r(\mathbf{i}, \mathbf{o}) \cos\theta_i \, d\mathbf{i}∫P​fr​(i,o)cosθi​di

这个积分对多边形光源没有闭式解。

LTC 的思路：

1. 找到一个线性变换 M，把"余弦分布"变换成目标 BRDF 的形状
2. 多边形光源在这个变换下仍然是多边形
3. 于是"BRDF 在多边形上的积分" = "余弦分布在新多边形上的积分"
4. 后者有解析解（经典的多边形辐照度公式）

fr≈clamped cosine(M−1ωo)⋅Jf_r \approx \text{clamped cosine}(M^{-1} \omega_o) \cdot Jfr​≈clamped cosine(M−1ωo​)⋅J

预计算：MMM 依赖(roughness,θv)(\text{roughness}, \theta_v)(roughness,θv​)，预存成 2D 纹理。

代价：只适用于 GGX 类型的 BRDF（形状能被线性变换近似），但正好覆盖常用情况。

价值：实时面光源 + 光泽材质的解析解，无需采样，无噪声。UE4 的 Rect Light 用它。

散射模型

participating media（参与介质）

光在介质内部传播时会被散射和吸收（雾、烟、牛奶、云、皮肤内部）。

辐射传输方程（RTE）：

dLdt=−σtL+σs∫S2p(ω′,ω)L(ω′)dω′+σaLe\frac{dL}{dt} = -\sigma_t L + \sigma_s \int_{S^2} p(\omega', \omega) L(\omega') d\omega' + \sigma_a L_edtdL​=−σt​L+σs​∫S2​p(ω′,ω)L(ω′)dω′+σa​Le​

关键结论：

L(t)=L0e−σtt+∫0te−σts(⋯ )dsL(t) = L_0 e^{-\sigma_t t} + \int_0^t e^{-\sigma_t s} (\cdots) dsL(t)=L0​e−σt​t+∫0t​e−σt​s(⋯)ds

Beer-Lambert 定律：T=e−σtdT = e^{-\sigma_t d}T=e−σt​d（透射率随距离指数衰减）。这是雾效的基础。

相位函数：

Henyey-Greenstein一个参数ggg 控制前向/后向偏好，最常用
Rayleigh大气（蓝天、红日落）
Mie大颗粒（云、雾）

g>0g > 0g>0 前向散射（雾）、g<0g < 0g<0 后向散射。

实时实现：

  • 解析雾：深度越大雾越浓（e−σtde^{-\sigma_t d}e−σt​d），几乎是免费的
  • 体积雾：3D 纹理（froxel）+ ray marching + 时域抖动降噪
  • 体积云：多层噪声 + ray marching（现代游戏的主要开销之一）

NPR（Non-Photorealistic Rendering）

目标不是"像照片"，而是"像某种艺术风格"。

风格做法
卡通/赛璐璐（Toon / Cel）把光照量化成几个色阶
描边（Outline）法线/深度边缘检测，或背面挤出法
素描/铅笔纹理化笔触
水墨边缘扩散 + 纸张纹理
半色调网点

卡通着色的实现

float ndotl = max(dot(N, L), 0.0);
// 平滑阶跃（避免硬边锯齿，用 smoothstep 而不是 step）
float toon = smoothstep(0.45, 0.5, ndotl);
vec3 color = mix(shadowColor, litColor, toon);

用 smoothstep 而不是 step：硬边会严重走样，smoothstep 给出抗锯齿的过渡。更好的做法是用贴图控制过渡曲线（美术可控）。

描边

方法 A: 背面法（Back-face / Inverted Hull）
   渲染两遍，第二遍只画背面 + 沿法线外扩 + 正面剔除
   → 得到轮廓
   优点: 简单，线宽可控（按距离调整外扩量）
   缺点: 硬边模型（立方体）会有断裂

方法 B: 屏幕空间边缘检测
   对深度和法线做 Sobel/Roberts 算子
   优点: 通用（也检测内部边缘、折痕）
   缺点: 需要后处理，线宽不随距离变化

方法 C: 几何着色器生成边

NPR 的关键认识

NPR 不是"不真实"，而是"有选择地不真实"。

好的 NPR 需要保留真实渲染的空间感（阴影、AO、材质），只改变表达方式。最差的 NPR 是直接把光照拍平。

复杂模型

BSSRDF（双向次表面散射反射分布函数）

问题：光进入半透明材质，在内部散射，从另一个位置射出。

BRDF 假设"入射点 = 出射点"，BSSRDF 允许不同：

S(xi,ωi;xo,ωo)S(\mathbf{x}_i, \omega_i; \mathbf{x}_o, \omega_o)S(xi​,ωi​;xo​,ωo​)

BRDF:   光进来 → 马上从同一点出去
BSSRDF: 光进来 → 在内部走一段 → 从另一点出去
                        ↑ 这就是"透光感"

典型材质：皮肤、玉、大理石、牛奶、蜡烛、水果。

皮肤为什么需要 BSSRDF：皮肤的散射半径约几毫米，所以：

  • 鼻翼、耳朵在逆光时会透红
  • 阴影边缘柔和（光"绕过"了）
  • 直接 BRDF 渲染会显得像塑料

次表面散射的近似：扩散剖面（Diffusion Profile）

Jensen 2001 的偶极子扩散近似：

Rd(r)=α′4π[e−σtrdrdr+e−σtrdvdv]R_d(r) = \frac{\alpha'}{4\pi} \left[ \frac{e^{-\sigma_{tr} d_r}}{d_r} + \frac{e^{-\sigma_{tr} d_v}}{d_v} \right]Rd​(r)=4πα′​[dr​e−σtr​dr​​+dv​e−σtr​dv​​]

Rd(r)R_d(r)Rd​(r) 描述"距离入射点rrr 处有多少光射出"——一个钟形的扩散剖面。

关键参数：

  • σa\sigma_aσa​：吸收（决定颜色）
  • σs′\sigma_s'σs′​：约化散射系数
  • 平均自由程1/σs′1/\sigma_s'1/σs′​：决定散射半径

实时实现：

方法做法
纹理空间扩散把物体 UV 展开成纹理，在纹理空间做模糊（多次高斯模糊），再映射回去
屏幕空间 SSS在后处理里按扩散剖面模糊
可分离 SSS把RdR_dRd​ 分解成若干高斯的和（通常 4~6 个），用卷积实现
预积分皮肤（Pre-Integrated Skin）预计算一个 LUT：(NdotL,curvature)→漫反射(\text{NdotL}, \text{curvature}) \to \text{漫反射}(NdotL,curvature)→漫反射

预积分皮肤 LUT（Penner 2011）最实用：

// LUT: 横轴 NdotL，纵轴 1/curvature（曲率半径的倒数）
vec3 skin = texture(sssLUT, vec2(NdotL * 0.5 + 0.5, curvature)).rgb;

曲率高的地方（鼻尖）散射更明显 → 更红。这解释了"为什么鼻尖特别容易红"。

hair（毛发）

毛发是各向异性的细圆柱，不能用普通 BRDF。

Marschner 模型（2003）——三个分量：

R:  直接反射（表面反射，白色高光）
TT: 透射-透射（穿过发丝两次，棕色，第二层高光）
TRT: 透射-反射-透射（内部反射一次，有色，第二层高光）

关键现象：

  • 双高光：主高光（白色）+ 次要高光（有色，位置偏移）
  • 各向异性高光：沿着发丝方向拉伸成条状

切线空间的约定：

T: 沿发丝方向（切线）
N: 法线
B: 副法线 = T × N

高光沿 T 方向拉伸

实时实现：

  • Kajiya-Kay（简化）：sin⁡\sinsin 项代替cos⁡\coscos，各向异性
  • Marschner：完整模型，用预计算的散射 LUT
  • 发丝渲染：通常用卡片（card）或曲线（strand）

现代：UE 的 Hair Strand（大量几何 + 专用着色模型），以及《毛发白皮书》的 d'Eon 改进模型（加入多次散射，让金发不至于太暗）。

skin（皮肤）

皮肤 = 多层结构：

┌─────────────┐
│  油脂层      │  镜面反射（很薄，Fresnel）
├─────────────┤
│  表皮        │  次表面散射（有色素，决定颜色）
├─────────────┤
│  真皮        │  血管（红色散射）
└─────────────┘

渲染要点：

  1. 双镜面高光（油脂层 + 表皮）：两个不同粗糙度的 lobe 叠加
  2. 次表面散射（见 BSSRDF）
  3. 细节贴图：毛孔、皱纹（法线贴图 + 微观 AO）
  4. 透射：耳朵、鼻翼逆光时的红

为什么皮肤难：人眼对人脸极度敏感（"恐怖谷"），任何不自然都会被察觉。

常见坑

  • roughness 直接用作α\alphaα：应该α=roughness2\alpha = \text{roughness}^2α=roughness2，否则 perceptual 不均匀
  • 忘了能量补偿：粗糙金属会显得太暗（多次散射损失）
  • 法线贴图的切线空间：切线空间算错会导致光照方向错误（最常见的 bug）
  • 非金属给了彩色F0F_0F0​：非金属的F0F_0F0​ 是灰白的（约 0.04），彩色F0F_0F0​ 只属于金属
  • metallic 中间值：metallic = 0.5 在物理上不存在（要么金属要么不是），会导致奇怪的结果。纹理里要避免半调值
  • SSS 的 UV 要求：纹理空间扩散需要良好无重叠的 UV，否则有拉伸
  • 头发的 tangent：必须沿发丝方向，用网格默认 tangent 会完全不同
  • NPR 的硬边走样：量化要用 smoothstep，不要用 step
  • HDR 与 tone mapping：PBR 的线性空间计算必须配 tone mapping（ACES 是现在的事实标准），否则高光会死白
  • gamma 校正：所有颜色纹理是 sRGB，计算必须在线性空间，最后再转回 sRGB。忘记这步会让整个画面偏暗偏灰
