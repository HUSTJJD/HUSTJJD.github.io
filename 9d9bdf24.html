17. Python：Jacobian、Beltrami 与奇异值

import numpy as np


def distortion_from_jacobian(J):
    """返回面积 Jacobian、奇异值比 K 和 |mu|。"""
    J = np.asarray(J, dtype=float).reshape(2, 2)
    det = np.linalg.det(J)
    sigma = np.linalg.svd(J, compute_uv=False)
    K = np.inf if sigma[1] == 0 else sigma[0] / sigma[1]
    mu_abs = 1.0 if np.isinf(K) else (K - 1.0) / (K + 1.0)
    return det, K, mu_abs


tests = {
    "similarity": [[0.0, -2.0], [2.0, 0.0]],
    "anisotropic": [[3.0, 0.0], [0.0, 1.0]],

    "flip": [[-1.0, 0.0], [0.0, 1.0]],
}

for name, J in tests.items():

    print(name, "det=", det, "K=", K, "|mu|=", mu_abs)

18. 常见逻辑错误

  1. 共形等于等距：错。共形允许位置相关的统一缩放。
  2. JTJ=λ2IJ^TJ=\lambda^2IJTJ=λ2I 就够了：若要求有向共形，还需det⁡J>0\det J>0detJ>0。
  3. 全纯函数处处共形：导数为 0 的分支点除外。
  4. 球面可共形无缝展开到有限平面：缺少投影点；需要极点或多张图。
  5. Riemann 映射适用于任意曲面：它是平面单连通域定理；一般曲面用一致化。
  6. 调和映射必共形：缺少能量-面积等号或 Hopf differential 为 0 等条件。
  7. ∣μ∣|\mu|∣μ∣ 越小面积畸变越小：μ\muμ 只控制各向异性，不控制统一尺度。
