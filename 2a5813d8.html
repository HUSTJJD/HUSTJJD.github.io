质点-弹簧系统

Base Knowledge, Computer Graphics, Simulation 2025-08-10 2026-10-10 3343 字

模型

**质点-弹簧系统（Mass-Spring System）**是最简单的弹性模型：

  • 质点：有质量的点，位置xi\mathbf{x}_ixi​、速度vi\mathbf{v}_ivi​
  • 弹簧：连接两个质点，产生弹力

用途：布料、头发、绳索、软体（粗糙近似）、果冻效果。

弹簧力

Hooke 定律

fi→j=k(∥xij∥−L)xij∥xij∥,xij=xj−xi\mathbf{f}_{i \to j} = k\left(\|\mathbf{x}_{ij}\| - L\right) \frac{\mathbf{x}_{ij}}{\|\mathbf{x}_{ij}\|}, \quad \mathbf{x}_{ij} = \mathbf{x}_j - \mathbf{x}_ifi→j​=k(∥xij​∥−L)∥xij​∥xij​​,xij​=xj​−xi​

其中kkk 是刚度，LLL 是静止长度。

注意力的方向：弹簧拉长时把两端往内拉，压缩时往外推。

对质点 i:  f_i = +k(||x_ij|| - L) · normalize(x_ij)
对质点 j:  f_j = -f_i                    （牛顿第三定律）

阻尼

没有阻尼的话，弹簧会永远振荡。阻尼模拟能量耗散：

fd=−kd[(vi−vj)⋅xij∥xij∥]xij∥xij∥\mathbf{f}_{d} = -k_d \left[(\mathbf{v}_i - \mathbf{v}_j) \cdot \frac{\mathbf{x}_{ij}}{\|\mathbf{x}_{ij}\|}\right] \frac{\mathbf{x}_{ij}}{\|\mathbf{x}_{ij}\|}fd​=−kd​[(vi​−vj​)⋅∥xij​∥xij​​]∥xij​∥xij​​

关键：只阻尼沿弹簧方向的相对速度（不是全部速度）——否则物体在自由下落时也会被"阻尼"，不符合物理。

完整的弹簧力：

f=k(∥xij∥−L)x^ij⏟弹力+kd(vij⋅x^ij)x^ij⏟阻尼\mathbf{f} = \underbrace{k(\|\mathbf{x}_{ij}\| - L)\hat{\mathbf{x}}_{ij}}_{\text{弹力}} + \underbrace{k_d (\mathbf{v}_{ij} \cdot \hat{\mathbf{x}}_{ij})\hat{\mathbf{x}}_{ij}}_{\text{阻尼}}f=弹力k(∥xij​∥−L)x^ij​​​+阻尼kd​(vij​⋅x^ij​)x^ij​​​

网格拓扑

不同的弹簧布置决定材料的性质。

布料常用：结构弹簧 + 剪切弹簧 + 弯曲弹簧

结构弹簧(structural)  剪切弹簧(shear)   弯曲弹簧(bend)
  抵抗拉伸              抵抗切变          抵抗折叠
类型连接作用刚度
结构上下左右相邻抵抗拉伸/压缩大
剪切对角防止网格切变成菱形中
弯曲隔一个点抵抗折叠（布料不会穿过自己）小

为什么需要三种：只有结构弹簧的话，网格会"塌"成菱形（切变无阻力），且会自由折叠（无弯曲刚度）。

真实布料的力学：弯曲刚度远小于拉伸刚度（布料很容易折，但很难拉长）。所以弯曲弹簧的kkk 应该设得很小。

时间积分

显式欧拉（会爆炸）

for each spring (i, j):
    f = springForce(xi, xj, vi, vj);
    force[i] += f;  force[j] -= f;
for each particle:
    force[i] += gravity * m[i];
    v[i] += dt * force[i] / m[i];
    x[i] += dt * v[i];

稳定性条件：

Δt≤2ωmax⁡,ωmax⁡≈kmax⁡mmin⁡\Delta t \le \frac{2}{\omega_{\max}}, \quad \omega_{\max} \approx \sqrt{\frac{k_{\max}}{m_{\min}}}Δt≤ωmax​2​,ωmax​≈mmin​kmax​​​

或更严格的工程估计：

Δt≤cmk,c≈0.1\Delta t \le c\sqrt{\frac{m}{k}}, \quad c \approx 0.1Δt≤ckm​​,c≈0.1

刚度大 → 时间步必须小 → 布料（需要大kkk 才不拉伸）很难显式积分。

半隐式（Symplectic）欧拉

只是交换顺序，稳定性大幅改善：

v[i] += dt * force[i] / m[i];     // 先更新速度
x[i] += dt * v[i];                // 再用新速度更新位置

为什么更好：它是辛积分器，长期能量有界（会在真实值附近振荡，不会单调发散）。

实时仿真的默认选择。

Verlet 积分

// 不显式存速度
vec3 xNew = 2 * x[i] - xOld[i] + dt*dt * force[i] / m[i];
xOld[i] = x[i];
x[i] = xNew;
// 速度可从 (x[i] - xOld[i]) / dt 推出

优点：简单、辛、能量稳定。 用途：布料（很多实现用 Verlet）、分子动力学。

稳定性问题的解法

1. 减小时间步（子步）

一帧 1/60 s，但物理跑 8 个子步 → 每步 dt = 1/480 s

简单有效，但线性增加成本。

2. 隐式积分

解 (M/dt² - ∂f/∂x) Δx = ...

稳定但每步要解线性系统（对弹簧系统，矩阵是稀疏对称正定的，可以用共轭梯度）。

3. 位置约束（PBD）

完全绕开"力"——直接约束长度。

// PBD 的距离约束
void solveDistance(int i, int j, float restLen) {
    vec3 d = x[j] - x[i];
    float len = length(d);
    if (len < 1e-6) return;
    vec3 corr = (len - restLen) / len * d;      // 需要移动的总量
    float wi = 1.0/m[i], wj = 1.0/m[j];
    x[i] += wi / (wi + wj) * corr;              // 按质量倒数分配
    x[j] -= wj / (wi + wj) * corr;
}

// 主循环
for (int iter = 0; iter < NUM_ITER; iter++)
    for (auto& c : constraints) c.solve();

优点：

  • 无条件稳定（不涉及刚度）
  • 迭代次数是"质量/性能"旋钮
  • 可以直接控制"布料有多硬"（迭代次数多 = 硬）

这是现代布料/软体仿真的主流方法。

4. 过松弛（Over-relaxation）

显式方法的一个廉价技巧：把修正量乘以一个大于 1 的系数（1.5~2），加速收敛。但太大会震荡。

布料仿真的完整流程

每一帧:
  1. 外力: 重力、风力、用户拖拽
  2. 预测位置: p = x + dt·v + dt²·M⁻¹·f_ext
  3. 约束求解（迭代 N 次）:
       - 距离约束（结构/剪切/弯曲弹簧）
       - 碰撞约束（与场景、自碰撞）
       - 固定点约束（钉住的角）
  4. 更新速度: v = (p - x) / dt
  5. 更新位置: x = p
  6. （可选）速度阻尼/摩擦

布料的特殊问题

1. 过度拉伸（super-elastic behavior）

PBD 迭代不足时，布料会像橡皮一样拉长。

解法：

  • 增加迭代次数
  • 长度上限约束（硬约束：如果超过L×1.1L \times 1.1L×1.1，直接截断）
  • Long Range Attachment（LRA）：给远处的点也加约束（模拟布料的"不可伸长"）

2. 自碰撞

布料穿过自己。

代价：O(n2)O(n^2)O(n2) 的碰撞对，实时很难。

实用近似：

  • 空间哈希做宽相
  • 只检测"相邻但不相邻"的点
  • 基于厚度：给每个点一个半径
  • 或者干脆不做（很多游戏接受穿模）

3. 与场景碰撞

1. 检测穿透（点 vs SDF / 三角形）
2. 投影出表面（沿法线推到外面）
3. 应用摩擦（切向速度衰减）

摩擦的实现（PBD 风格）：

// 碰撞后
vec3 vn = dot(v, n) * n;         // 法向分量
vec3 vt = v - vn;                // 切向分量
v = vt * (1 - friction);         // 切向衰减（摩擦）
if (dot(vn, n) < 0) v -= vn;     // 移除穿透速度（或加弹性）

4. 风力

fwind=12ρ∣vrel∣2⋅A⋅(n⋅vrel)n\mathbf{f}_{wind} = \frac{1}{2}\rho |\mathbf{v}_{rel}|^2 \cdot A \cdot (\mathbf{n} \cdot \mathbf{v}_{rel}) \mathbf{n}fwind​=21​ρ∣vrel​∣2⋅A⋅(n⋅vrel​)n

按面计算（不是按点）：风力正比于面法线与相对速度的夹角（n⋅vreln \cdot v_{rel}n⋅vrel​），然后按面积分配到三个顶点。

只按点算风力的效果会很差（布料不会"鼓起来"）。

参数调优经验

参数影响典型值
刚度kkk拉伸程度布越大（越不想拉伸）
阻尼kdk_dkd​振荡衰减太大会显得"黏"
时间步Δt\Delta tΔt稳定性1/60 ~ 1/240
PBD 迭代次数硬度4~20
质量惯性均匀即可

常见调参顺序：

  1. 先让它稳定（调Δt\Delta tΔt 或加迭代）
  2. 再调刚度（不拉伸）
  3. 最后调阻尼（自然感）

局限

质点-弹簧不是真正的弹性力学：

问题说明
刚度依赖网格拓扑同样的kkk，粗网格和细网格表现不同
各向异性沿网格方向和对角方向的力学性质不同
泊松比难控制真实的体积保持/不可压缩难以表达
无连续介质保证细化网格不会收敛到连续解

真正的弹性体仿真要用有限元（FEM）——见柔体。

但对布料来说，质点-弹簧（或 PBD）够用，因为布料本来就不是连续介质（是编织物），"看起来对"就行。

常见坑

  • 弹簧力的方向搞反：拉长时应该往内拉
  • 阻尼阻尼了全部速度：应该只阻尼沿弹簧的相对速度分量，否则自由落体的物体会被"刹住"
  • 显式积分爆炸：刚度大时一定要子步或换隐式/PBD
  • 忘了牛顿第三定律：一端加力另一端要减力
  • 弯曲弹簧刚度太大：布料变硬板，不自然。弯曲刚度应远小于拉伸刚度
  • 固定点处理：质量设为无穷大（或 invMass = 0），而不是"每帧强制设回位置"（后者会导致速度不一致）
  • PBD 的速度更新：v = (p - x) / dt 要在约束求解之后，否则速度不对
  • 自碰撞的成本：O(n2)O(n^2)O(n2) 会拖垮性能，一定要空间划分，且考虑是否真的需要
  • 布料的"鼓起"：需要按面计算风力，按点算没有这个效果
  • 穿透后弹飞：投影距离太大导致能量注入。要限制单帧最大修正量
