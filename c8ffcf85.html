本章目标

参数化可以通过求坐标实现，也可以通过改度量实现：在同一共形类内调节局部尺度，使高斯曲率达到目标分布，然后把所得平坦/球面/双曲度量发展到标准空间。

1. 连续二维 Ricci 流

一般 Ricci 流：

∂g∂t=−2Ric⁡(g).\frac{\partial g}{\partial t}=-2\operatorname{Ric}(g).∂t∂g​=−2Ric(g).

二维中

Ric⁡=Kg,\operatorname{Ric}=Kg,Ric=Kg,

所以

∂g∂t=−2Kg.\frac{\partial g}{\partial t}=-2Kg.∂t∂g​=−2Kg.

这是纯共形变化。若g(t)=e2u(t)g0g(t)=e^{2u(t)}g_0g(t)=e2u(t)g0​，则

2∂u∂tg=−2Kg,2\frac{\partial u}{\partial t}g =-2Kg,2∂t∂u​g=−2Kg,

故

∂u∂t=−K.\frac{\partial u}{\partial t}=-K.∂t∂u​=−K.

1.1 归一化 Ricci 流

为了保持面积，使用平均曲率

Kˉ=∫MK,dAArea⁡(M)=2πχ(M)Area⁡(M),\bar K=\frac{\int_MK,dA}{\operatorname{Area}(M)} =\frac{2\pi\chi(M)}{\operatorname{Area}(M)},Kˉ=Area(M)∫M​K,dA​=Area(M)2πχ(M)​,

并令

∂g∂t=−2(K−Kˉ)g,∂u∂t=Kˉ−K.\boxed{ \frac{\partial g}{\partial t} =-2(K-\bar K)g, \qquad \frac{\partial u}{\partial t}=\bar K-K. }∂t∂g​=−2(K−Kˉ)g,∂t∂u​=Kˉ−K.​

曲率高于平均处收缩，低于平均处膨胀，最终趋向常曲率度量（在相应条件下）。

2. 共形曲率变换与 Yamabe 方程

若

g~=e2ug,\tilde g=e^{2u}g,g~​=e2ug,

二维曲率满足

Kg~=e−2u(Kg−Δgu).K_{\tilde g}=e^{-2u}(K_g-\Delta_gu).Kg~​​=e−2u(Kg​−Δg​u).

给定目标曲率Kˉ(x)\bar K(x)Kˉ(x)，求uuu 满足

−Δgu+Kg=Kˉe2u.\boxed{-\Delta_gu+K_g=\bar K e^{2u}.}−Δg​u+Kg​=Kˉe2u.​

它是非线性椭圆 PDE。Gauss–Bonnet 给出必要兼容条件：

∫MKˉ,dAg~=2πχ(M).\int_M\bar K,dA_{\tilde g}=2\pi\chi(M).∫M​Kˉ,dAg~​​=2πχ(M).

离散情形也必须满足目标曲率总和约束。

3. 离散曲率处方问题

给定三角网格和初始内在边长lij0l_{ij}^0lij0​，寻找离散共形因子uiu_iui​，产生新边长lij(u)l_{ij}(u)lij​(u)，使

目标曲率必须满足：

∑i∈V∘Kˉi+∑i∈∂Vkˉi=2πχ(M).\sum_{i\in V^\circ}\bar K_i +\sum_{i\in\partial V}\bar k_i =2\pi\chi(M).i∈V∘∑​Kˉi​+i∈∂V∑​kˉi​=2πχ(M).

此外还存在局部可实现性不等式；只满足总和通常不够。

4. 两类离散共形度量

4.1 Circle packing / circle pattern

给每个顶点圆半径ri=euir_i=e^{u_i}ri​=eui​。在欧氏背景中，一种常见边长模型：

lij2=ri2+rj2+2rirjcos⁡Φij,l_{ij}^2 =r_i^2+r_j^2+2r_ir_j\cos\Phi_{ij},lij2​=ri2​+rj2​+2ri​rj​cosΦij​,

其中Φij\Phi_{ij}Φij​ 是交角。相切圆对应Φij=0\Phi_{ij}=0Φij​=0，于是lij=ri+rjl_{ij}=r_i+r_jlij​=ri​+rj​。

4.2 Vertex scaling

以已有边长为基准：

lij(u)=e(ui+uj)/2lij0.\boxed{l_{ij}(u)=e^{(u_i+u_j)/2}l_{ij}^0.}lij​(u)=e(ui​+uj​)/2lij0​.​

它是连续共形缩放的离散对应。每个三角形角度由新边长通过余弦定理计算。

固定 triangulation 时，某些uuu 会使三角不等式失效。现代离散共形理论通常允许执行 intrinsic Delaunay flip，使算法跨越不同三角剖分单元。

5. 离散 Ricci/Yamabe 流

最直接的 ODE：

duidt=Kˉi−Ki(u).\boxed{ \frac{du_i}{dt}=\bar K_i-K_i(u). }dtdui​​=Kˉi​−Ki​(u).​

显式 Euler：

ui(n+1)=ui(n)+Δt(Kˉi−Ki(u(n))).u_i^{(n+1)} =u_i^{(n)}+\Delta t(\bar K_i-K_i(u^{(n)})).ui(n+1)​=ui(n)​+Δt(Kˉi​−Ki​(u(n))).

它直观但步长受稳定性限制。更快方法利用变分能量和 Hessian 做 Newton 迭代。

6. 曲率映射的 Jacobian

在固定组合结构和合法度量区域内，离散曲率对uuu 的导数构成对称矩阵：

Hij=∂Ki∂uj.H_{ij}=\frac{\partial K_i}{\partial u_j}.Hij​=∂uj​∂Ki​​.

在常见欧氏 vertex scaling 约定中，HHH 是余切 Laplace 型矩阵（具体符号和1/21/21/2 因子依uuu 定义而异）：

Hij∝−wij,i≠j,H_{ij}\propto -w_{ij},\quad i\ne j,Hij​∝−wij​,i=j,

Hii=−∑j≠iHij.H_{ii}=-\sum_{j\ne i}H_{ij}.Hii​=−j=i∑​Hij​.

因此：

  • HHH 对称；
  • H1=0H\mathbf1=0H1=0，统一加常数只改变整体尺度；
  • 固定尺度后通常正定/半正定；
  • 曲率处方可写成凸优化。

10. 从目标曲率得到标准参数域

10.1 球面型：χ>0\chi>0χ>0

闭 genus-0 曲面目标常取常正曲率。得到球面度量后，用发展映射或离散嵌入恢复S2S^2S2 上坐标，再用 Möbius 归一化消除自由度。

10.2 欧氏型：χ=0\chi=0χ=0

环面目标曲率全为 0，得到平坦度量。沿同调基切开并发展到平面，获得平行四边形周期域。

带边界圆盘常将内部曲率设为 0，并将边界曲率集中或均匀分布，使其展开为平面多边形。

12. 离散曲率流伪代码

input: triangulation T, initial lengths l0, target curvature K_bar
u <- 0
fix scale gauge, e.g. sum(u) = 0

repeat:
    l <- conformal_lengths(l0, u)
    while T is not intrinsic Delaunay:
        flip offending edge
        update intrinsic length with Ptolemy relation

    theta <- triangle_angles(l)
    K <- angle_defects(theta)
    residual <- K - K_bar
    if max_abs(residual) < tolerance: break

    H <- curvature_jacobian(theta)  # Laplace-type Hessian
    du <- solve_gauged_system(H, -residual)
    step <- backtracking_line_search(u, du)
    u <- u + step * du

output: conformal factor u, final intrinsic metric l, triangulation T

15. 常见错误

  1. 目标曲率不满足 Gauss–Bonnet，问题根本无解。
  2. 忘记固定尺度，Hessian 奇异。
  3. 固定原三角剖分不翻边，迭代撞上三角不等式边界。
  4. 把角度亏损当作曲率密度；二者相差 dual area。
  5. Newton 不做 line search，远离解时发散。
  6. 得到目标度量后直接把原三维坐标当作参数坐标；仍需发展映射。
  7. 球面/双曲参数未做自同构归一化，比较结果会漂移。
