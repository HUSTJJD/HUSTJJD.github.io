# 离散微分几何# 有限元# Tutte# LSCM

自动关联目录：离散曲面与共形算法

本页是集中复习用的长篇参考。第一次学习请进入 模块 5：离散曲面与共形算法，按 10 个单概念短课阅读。

本章目标

连续理论给出度量、曲率、Laplacian 和共形结构；算法必须把它们转成有限维数据。本章从三角网格出发，逐步推导：

边长→三角形角度与面积→角度亏损→余切能量→稀疏 Laplace 矩阵→调和/共形参数化.\text{边长} \to \text{三角形角度与面积} \to \text{角度亏损} \to \text{余切能量} \to \text{稀疏 Laplace 矩阵} \to \text{调和/共形参数化}.边长→三角形角度与面积→角度亏损→余切能量→稀疏 Laplace 矩阵→调和/共形参数化.

1. 三角剖分曲面

一个定向三角网格记为

M=(V,E,F),M=(V,E,F),M=(V,E,F),

其中VVV 是顶点，EEE 是边，FFF 是有向三角形。几何嵌入给每个顶点位置pi∈R3p_i\in\mathbb R^3pi​∈R3。

1.1 组合结构与几何结构要分开

  • 组合结构：哪些顶点、边、面相邻；
  • 分片线性几何：每条边的长度lijl_{ij}lij​；
  • 外在嵌入：顶点在R3\mathbb R^3R3 中的位置。

离散内在度量只需边长，并要求每个三角形满足严格三角不等式：

lij+ljk>lki.l_{ij}+l_{jk}>l_{ki}.lij​+ljk​>lki​.

同一组边长可以有不同三维折叠，但内在角度、面积和离散曲率相同。

1.2 半边结构

每条无向边拆成两个定向半边h=(i→j)h=(i\to j)h=(i→j) 与h∗=(j→i)h^*=(j\to i)h∗=(j→i)。每个半边至少记录：

origin(h) : 起点
next(h)   : 同一面中的下一条半边
twin(h)   : 反向半边；边界处可为空
face(h)   : 所属面
edge(h)   : 所属无向边

常数时间可完成：

  • 沿面循环：h -> next(h)；
  • 穿过边：h -> twin(h)；
  • 绕顶点：h -> twin(next(h))（具体公式随约定变化）。

2. 从边长恢复单个三角形

三角形(i,j,k)(i,j,k)(i,j,k) 的边长记为

a=ljk,b=lki,c=lij.a=l_{jk},\quad b=l_{ki},\quad c=l_{ij}.a=ljk​,b=lki​,c=lij​.

余弦定理：

cos⁡θi=b2+c2−a22bc.\cos\theta_i=\frac{b^2+c^2-a^2}{2bc}.cosθi​=2bcb2+c2−a2​.

Heron 公式：

s=a+b+c2,A=s(s−a)(s−b)(s−c).s=\frac{a+b+c}{2}, \qquad A=\sqrt{s(s-a)(s-b)(s-c)}.s=2a+b+c​,A=s(s−a)(s−b)(s−c)​.

也可在局部二维坐标中放置

qi=(0,0),qj=(c,0),q_i=(0,0),\quad q_j=(c,0),qi​=(0,0),qj​=(c,0),

qk=(b2+c2−a22c,b2−xk2).q_k=\left( \frac{b^2+c^2-a^2}{2c}, \sqrt{b^2-x_k^2} \right).qk​=(2cb2+c2−a2​,b2−xk2​​).

所有三角形内的梯度、Jacobian 和能量都可在这个局部坐标中计算。

3. 分片平坦度量与锥奇点

每个三角形内部是欧氏平面，沿边按等长方式粘合。曲率只集中在顶点，顶点邻域像一个欧氏圆锥。

内部顶点iii 的总角为

Θi=∑t∋iθit.\Theta_i=\sum_{t\ni i}\theta_i^t.Θi​=t∋i∑​θit​.

离散高斯曲率（角度亏损）为

Ki=2π−Θi.\boxed{K_i=2\pi-\Theta_i.}Ki​=2π−Θi​.​

边界顶点的边界曲率为

ki=π−Θi.\boxed{k_i=\pi-\Theta_i.}ki​=π−Θi​.​

这里KiK_iKi​ 是积分曲率，不是除以面积后的曲率密度。若需近似点值曲率，可除以 barycentric 或 Voronoi dual area。

4. 离散 Gauss–Bonnet 的推导

设网格有边界。将所有顶点曲率求和：

∑i∈V∘(2π−Θi)+∑i∈∂V(π−Θi).\sum_{i\in V^\circ}(2\pi-\Theta_i) +\sum_{i\in\partial V}(\pi-\Theta_i).i∈V∘∑​(2π−Θi​)+i∈∂V∑​(π−Θi​).

每个三角形内角和为π\piπ，所以

∑iΘi=πF.\sum_i\Theta_i=\pi F.i∑​Θi​=πF.

记内部顶点数ViV_iVi​、边界顶点数VbV_bVb​：

∑Ki=2πVi+πVb−πF.\sum K_i=2\pi V_i+\pi V_b-\pi F.∑Ki​=2πVi​+πVb​−πF.

对三角网格，数面-边关联：

3F=2Ei+Eb,3F=2E_i+E_b,3F=2Ei​+Eb​,

每条边界分支是闭合多边形，所以Eb=VbE_b=V_bEb​=Vb​。代数化简得到

∑i∈V∘Ki+∑i∈∂Vki=2π(V−E+F)=2πχ(M).\boxed{ \sum_{i\in V^\circ}K_i+ \sum_{i\in\partial V}k_i =2\pi(V-E+F)=2\pi\chi(M). }i∈V∘∑​Ki​+i∈∂V∑​ki​=2π(V−E+F)=2πχ(M).​

离散 Gauss–Bonnet 对任意三角剖分严格成立，不是收敛意义下的近似。

5. 分片线性有限元基函数

对每个顶点iii，定义帽函数ϕi\phi_iϕi​：

ϕi(pj)=δij,\phi_i(p_j)=\delta_{ij},ϕi​(pj​)=δij​,

并在每个三角形内线性。任意分片线性函数

uh=∑iuiϕi.u_h=\sum_i u_i\phi_i.uh​=i∑​ui​ϕi​.

在每个三角形内∇ϕi\nabla\phi_i∇ϕi​ 为常向量。

20. Python：组装余切 Laplacian

import numpy as np
from scipy.sparse import coo_matrix


def cotangent(u, v, eps=1e-15):
    cross = np.linalg.norm(np.cross(u, v))
    if cross <= eps:
        raise ValueError("degenerate triangle")
    return float(np.dot(u, v) / cross)


def cotangent_laplacian(vertices, faces):
    n = len(vertices)
    weights = {}

    for i, j, k in np.asarray(faces, dtype=int):
        pi, pj, pk = vertices[[i, j, k]]
        cot_i = cotangent(pj - pi, pk - pi)
        cot_j = cotangent(pk - pj, pi - pj)
        cot_k = cotangent(pi - pk, pj - pk)

        for (a, b), value in [
            ((j, k), 0.5 * cot_i),
            ((k, i), 0.5 * cot_j),
            ((i, j), 0.5 * cot_k),
        ]:
            edge = tuple(sorted((a, b)))
            weights[edge] = weights.get(edge, 0.0) + value

    rows, cols, data = [], [], []
    diagonal = np.zeros(n)
    for (i, j), w in weights.items():
        rows += [i, j]
        cols += [j, i]
        data += [-w, -w]
        diagonal[i] += w
        diagonal[j] += w

    rows.extend(range(n))
    cols.extend(range(n))
    data.extend(diagonal)
    return coo_matrix((data, (rows, cols)), shape=(n, n)).tocsr()


def validate_laplacian(L, atol=1e-10):
    symmetry = np.max(np.abs((L - L.T).data), initial=0.0)
    row_sum = np.max(np.abs(np.asarray(L.sum(axis=1)).ravel()))
    if symmetry > atol or row_sum > atol:
        raise ValueError((symmetry, row_sum))

21. Python：单三角形 Jacobian 与畸变

def local_triangle_2d(p0, p1, p2):
    e1 = p1 - p0
    length = np.linalg.norm(e1)
    if length <= 1e-15:
        raise ValueError("zero edge")
    x_axis = e1 / length
    normal = np.cross(e1, p2 - p0)
    area2 = np.linalg.norm(normal)
    if area2 <= 1e-15:
        raise ValueError("degenerate triangle")
    normal /= area2
    y_axis = np.cross(normal, x_axis)
    return np.array([
        [0.0, 0.0],
        [length, 0.0],
        [np.dot(p2 - p0, x_axis), np.dot(p2 - p0, y_axis)],
    ])


def triangle_distortion(points_3d, uv):
    x = local_triangle_2d(*points_3d)
    X = np.column_stack((x[1] - x[0], x[2] - x[0]))
    U = np.column_stack((uv[1] - uv[0], uv[2] - uv[0]))
    J = U @ np.linalg.inv(X)
    sigma = np.linalg.svd(J, compute_uv=False)
    det = np.linalg.det(J)
    K = np.inf if sigma[1] <= 1e-15 else sigma[0] / sigma[1]
    return {"J": J, "det": det, "sigma": sigma, "K": K}

  3. 实现 LSCM 局部矩阵组装，用两个锚点求解。
  4. 输出每个三角形的log⁡Kt\log K_tlogKt​、log⁡∣det⁡Jt∣\log|\det J_t|log∣detJt​∣ 热图。
  5. 对同一网格执行 intrinsic Delaunay flips，比较负权重数量。

24. 本章结论
