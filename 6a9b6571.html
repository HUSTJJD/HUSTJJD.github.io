Navier-Stokes 方程

流体仿真的控制方程：

ρ(∂u∂t+u⋅∇u)=−∇p+μ∇2u+f\rho\left(\frac{\partial \mathbf{u}}{\partial t} + \mathbf{u}\cdot\nabla\mathbf{u}\right) = -\nabla p + \mu\nabla^2\mathbf{u} + \mathbf{f}ρ(∂t∂u​+u⋅∇u)=−∇p+μ∇2u+f

∇⋅u=0（不可压缩条件）\nabla\cdot\mathbf{u} = 0 \quad \text{（不可压缩条件）}∇⋅u=0（不可压缩条件）

项名称含义
∂u∂t\frac{\partial \mathbf{u}}{\partial t}∂t∂u​非定常项速度随时间变化
u⋅∇u\mathbf{u}\cdot\nabla\mathbf{u}u⋅∇u对流项流体带着自己走（非线性，难点）
−∇p-\nabla p−∇p压力项压力驱动（维持不可压缩）
μ∇2u\mu\nabla^2\mathbf{u}μ∇2u粘性项内摩擦
f\mathbf{f}f外力重力、浮力

Stable Fluids（欧拉网格法）

Jos Stam 1999，实时流体仿真的奠基工作。

核心思想：算子分裂（operator splitting）——把方程拆成几步分别处理：

每一步:
  1. 加外力:      u += dt · f
  2. 对流:        u ← advect(u)          （半拉格朗日，稳定）
  3. 粘性扩散:    u ← diffuse(u)         （隐式求解）
  4. 投影:        u ← project(u)         （解压力泊松方程，使 ∇·u = 0）

为什么叫 "Stable"：每一步都用无条件稳定的方法（半拉格朗日对流 + 隐式扩散 + 隐式投影），所以任意大的时间步都不会爆炸。

1. 对流（半拉格朗日）

关键技巧：沿速度场回溯。

要算格子 (i,j) 在 t+dt 的速度:
  1. 从 (i,j) 沿 -u 回溯 dt:  p = (i,j) - dt·u(i,j)
  2. 在 p 处插值当前速度场
  3. 该值就是 (i,j) 的新速度
vec2 advect(vec2 pos, float dt, const Grid& vel) {
    vec2 p = pos - dt * vel.sample(pos);
    return vel.sample(p);              // 双线性插值
}

为什么稳定：不是"往前推"（会超出去），而是"往回找"（永远在已知区域内）。这叫半拉格朗日（semi-Lagrangian）。

代价：数值耗散——插值会抹平细节。烟会变得模糊。

改进：

  • MacCormack / BFECC：二阶精度，减少耗散
  • 高阶插值（三次插值）

2. 投影（压力求解）

目标：让速度场散度为零（不可压缩）。

数学上：

unew=u−∇p,∇2p=∇⋅u\mathbf{u}^{new} = \mathbf{u} - \nabla p, \quad \nabla^2 p = \nabla\cdot\mathbf{u}unew=u−∇p,∇2p=∇⋅u

这是一个泊松方程（Poisson equation），需要求解。

离散化后是大型稀疏线性系统：

Ap=b\mathbf{A}\mathbf{p} = \mathbf{b}Ap=b

求解方法：

方法复杂度特点
Gauss-Seidel / Jacobi 迭代简单收敛慢，但 GPU 友好的 Jacobi 很常用
共轭梯度（CG）快需要对称正定（这里是）
多重网格（Multigrid）最快实现复杂
FFT周期边界下最快边界限制

实时仿真中，投影是最贵的一步（通常占 70%+ 的时间）。

// Jacobi 迭代求解压力
for (int iter = 0; iter < N; iter++) {
    for each cell (i,j):
        p_new[i][j] = (p[i-1][j] + p[i+1][j] + p[i][j-1] + p[i][j+1]
                       - dx*dx * divergence[i][j]) / 4;
    swap(p, p_new);
}

// 应用压力梯度
for each cell:
    u[i][j] -= (p[i+1][j] - p[i-1][j]) / (2*dx);
    v[i][j] -= (p[i][j+1] - p[i][j-1]) / (2*dx);

3. 边界条件

固体边界:  法向速度为 0（流体不能穿透）
           u · n = 0
自由表面:  p = 0（大气压）

处理：在网格外设置"ghost cell"，或用标记（solid/fluid/air）。

PBF（Position Based Fluids，2013）

用 PBD 的思路做流体——把不可压缩性当作密度约束。

1. 预测位置: p = x + dt·v + dt²·f_ext
2. 迭代（几次）:
     对每个粒子:
       计算密度 ρ_i
       约束 C_i = ρ_i/ρ_0 - 1 = 0
       计算 Δp_i（沿约束梯度方向移动）
     应用 Δp
3. 更新速度: v = (p - x)/dt
4. （可选）XSPH 粘性、涡量补偿

优势：

  • 大时间步稳定（PBD 的固有优势）
  • 密度约束直接保证不可压缩
  • 比 SPH 好调参

这是当前实时流体（游戏、交互应用）的主流方法之一。

PIC / FLIP（混合方法）

粒子 + 网格：

PIC/FLIP 的一步:
  1. 粒子 → 网格:  把粒子速度累加到网格（加权）
  2. 网格求解:     在网格上加力、投影（使散度为零）
  3. 网格 → 粒子:  把网格速度插值回粒子

PIC（Particle-in-Cell）：直接用网格速度覆盖粒子速度。 → 稳定但耗散大（流体变"黏"）。

FLIP（Fluid Implicit Particle）：用速度的变化量Δu\Delta uΔu 更新粒子。

upnew=upold+Δugridu_p^{new} = u_p^{old} + \Delta u_{grid}upnew​=upold​+Δugrid​

→ 几乎无耗散，细节丰富。

问题：FLIP 会有噪声（粒子速度不受网格平滑约束）。

实用做法：PIC 和 FLIP 混合：

upnew=α⋅uPIC+(1−α)⋅uFLIP,α≈0.01u_p^{new} = \alpha \cdot u_{PIC} + (1-\alpha) \cdot u_{FLIP}, \quad \alpha \approx 0.01upnew​=α⋅uPIC​+(1−α)⋅uFLIP​,α≈0.01

取一点点 PIC 来抑制噪声，其余用 FLIP 保留细节。

这是影视级流体（Houdini、Maya Bifrost）的标准方法。

涡量约束（Vorticity Confinement）

问题：数值耗散让烟失去小尺度涡旋，看起来"死板"。

解法：主动检测涡量ω=∇×u\boldsymbol{\omega} = \nabla \times \mathbf{u}ω=∇×u，施加一个力增强已有的涡旋。

fvort=ϵ(N×ω),N=∇∣ω∣∥∇∣ω∣∥\mathbf{f}_{vort} = \epsilon (\mathbf{N} \times \boldsymbol{\omega}), \quad \mathbf{N} = \frac{\nabla|\boldsymbol{\omega}|}{\|\nabla|\boldsymbol{\omega}|\|}fvort​=ϵ(N×ω),N=∥∇∣ω∣∥∇∣ω∣​

这是让烟"活起来"的关键技巧——没有它，实时烟看起来像雾。

fbuoy=−αρg+β(T−Tambient)g\mathbf{f}_{buoy} = -\alpha \rho \mathbf{g} + \beta(T - T_{ambient})\mathbf{g}fbuoy​=−αρg+β(T−Tambient​)g

常见坑

  • 半拉格朗日对流太耗散：用 MacCormack 或提高分辨率
  • 压力求解不收敛：迭代次数不够 → 流体"可压缩"（会看到体积变化）
  • 边界条件不对：流体从墙里漏出来，或吸附在墙上
  • SPH 的粒子聚集：换核函数，或加人工压力项
  • SPH 边界密度偏低：加 ghost particle 或边界粒子层
  • FLIP 的噪声：混合一点 PIC
  • 时间步太大：即使 Stable Fluids 稳定，大Δt\Delta tΔt 也会让对流失真（CFL 条件：Δt<Δx/∣u∣\Delta t < \Delta x / |\mathbf{u}|Δt<Δx/∣u∣）
  • Level Set 没重新初始化：距离场失真，表面变形
  • 渲染时的折射：水的折射需要处理，直接画表面会很假
  • 粒子数与性能：几万粒子在 CPU 上就满了，需要 GPU（或降低维度）
